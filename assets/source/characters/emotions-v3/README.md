# 인물별 희노애락 생성 원본

사용자가2026-11-11확정한 “각 인물 최소5종·희노애락”의 부족한 카드와 두 아이의 개별 기본 그림을 담은165개PNG다. 원본을 실행 최적화 파일로 덮어쓰지 않는다. [선정·검토·재개](../../../../docs/architecture/evidence/all-character-emotions-2026-11-11/review.md), [원본/실행해시·변환](../../../../docs/architecture/evidence/all-character-emotions-2026-11-11/generation.json)을 따른다.

저장소 루트에서 `python3 scripts/prepare-expression-assets.py`로 검사한다. 실행WebP가 없는 경우에만 `--restore`로 복원하며 이미 수정된 파일은 보존한다. 기존 서비스/편집 자료의 사용 범위이며 CC0·무제한 자료실 허가가 아니다.
