# 네 작품 인물 동작·표정 생성 원본

16개 개별 PNG는 기존 인물 정체성·복식·화풍을 참조해2026-11-11 사용자 요청으로 생성했다. 실행 WebP와 별도 보관한다. [생성 해시·변환](../../../../docs/architecture/evidence/character-expression-expansion-2026-11-11/generation.json), [선정·검토·재개 절차](../../../../docs/architecture/evidence/character-expression-expansion-2026-11-11/review.md)를 따른다.

저장소 루트에서 `python3 scripts/prepare-expression-assets.py`로 검사한다. 실행WebP가 없을 때만 `--restore`를 붙인다. 이미 수정된 파일은 보존한 채 중단한다. 기존 서비스/편집 자료 사용 범위이며 CC0·무제한 재배포 허가는 아니다.
