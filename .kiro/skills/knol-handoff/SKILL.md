# 인수인계 문서

새 에이전트가 이어 갈 수 있게 지금 대화를 요약한다. 같은 Kiro에서 이어 갈 때는 필요 없다. 이 문서는 들고 다니기 위한 것이다.

## 저장 위치
운영체제 임시 폴더(`$TMPDIR`, 없으면 `/tmp`)의 `knolstory-handoff-<YYYYMMDD-HHMM>.md`. 작업 공간에 두지 않는다. 같은 사실이 정식 문서와 이 파일 두 곳에 남으면 어긋나기 때문이다. 다른 컴퓨터로 옮길 때는 사용자가 파일을 직접 옮긴다.

## 내용
- 목적: 사용자가 `/knol-handoff` 뒤에 적은 다음 세션의 목적(없으면 대화에서 판단).
- 현재 위치: 브랜치, HEAD SHA, 미커밋 파일 목록(누가 만든 것인지 구분), 실행 중 프로세스.
- 끝난 것과 남은 것: 원래 목표 기준으로. 남은 것은 실행 순서대로.
- 정한 것과 이유: 대화에서 결정됐지만 아직 정식 문서에 없는 것만. 이미 기록된 것은 경로나 링크로만 가리킨다(spec, 계획, ADR, checkpoint, 커밋, PR).
- 주의: 실패했던 시도와 그 원인, 건드리면 안 되는 것.
- 다음 도구별 시작 안내:
  - Kiro: `/knol-status`로 시작. 미커밋 변경이 있으면 `knol-resume`이 자동으로 쓰인다. 이어서 쓸 스킬 이름.
  - Codex: 저장소 `AGENTS.md`와 관련 `.agents/skills/<이름>/SKILL.md`를 먼저 읽게 한다.

## 가리기
API 키, 쿠키, 토큰, wrangler 자격 증명, 개인정보(이메일, 계정 ID), 원고 본문은 넣지 않는다. 로컬 절대 경로 대신 저장소 루트 기준 상대 경로를 쓴다.

## 끝
파일 경로를 사용자에게 알려 주고, 다음 세션에서 붙여 넣을 첫 문장(예: "이 인수인계 문서를 읽고 이어서 진행해: <경로>")을 함께 준다.
