# 원작·놀스토리 각색 음원 연출 제안

작성: 2026-10-13

추가 확보 반영: 이후 CC0 배경음 6곡을 더 확보하여 [최신 장·컷 표](STORY_AUDIO_TABLES.md)의 모든 범위에 배경음 후보를 마련했다. 아래 무음·미선정 배경음은 초기 연출안이며, 현재 선곡은 [추가 배경음 안내](CC0_BGM_SUPPLEMENT.md)와 최신 표를 우선한다. 정확한 효과음·환경음 부족은 계속 비워 둔다.

이 문서는 `LUCKYBRIDGE/story-maker` 깃허브의 대본을 읽고, 현재 확보한 CC0 음원 중 어떤 소리를 어느 구간에 쓰면 좋을지 정리한 **텍스트 제안서**다. 뉴놀스토리의 실행 가능한 작품이나 최신 개발 로컬을 확인했다는 뜻은 아니다. 대본·작품 파일에 음원을 등록하거나 재생 기능을 구현하지 않았다.

기준 버전은 `18da4fc5bd4bf2a9080b32903d31f1aacdd24a0b`이다. 2026-10-13 GitHub API에서 확인한 `story-maker` HEAD도 이 버전이었다. 작품 구분은 저장소의 ‘원작’과 ‘놀스토리’ 구분을 따른다. 여기서 원작은 학술적인 원전 전체가 아니라 **리포지토리에 수록된 원작 읽기 대본**이다. 숏스토리와 학생별 창작본은 이번 제안 대상에 포함하지 않는다.

현재 음원은 [CC0 음원 안내](CC0_AUDIO_GUIDE.md)의 401개 확보본을 기준으로 한다. 다른 개발 로컬의 기존 음원은 아직 대조하지 못했다. 아래 후보의 분위기는 배포자 설명과 파일명에 근거한 제안이며, 전체 청취로 확정한 최종 선곡은 아니다.

작품별 실제 장 ID·컷 범위·배경음·환경음·효과음은 [장·컷 음원 제안표](STORY_AUDIO_TABLES.md)에 정리했다. 컷 단위로 확인한 날씨·시간 경과·문 종류의 세부 범위는 이 표를 따른다.

## 1. 소리를 이어 쓰는 기준

**컷이 넘어가거나 장 제목이 바뀌어도, 같은 장소·날씨·감정이 이어지면 같은 소리를 계속 쓴다.** 예를 들어 겨울 문턱에서 가족의 의논으로 이어지는 대화마다 새 음악을 넣지 않는다. 한 곡을 낮게 유지하거나 음악을 잠시 낮춰 대화에 집중하게 한다.

- **배경음악:** 한 장면 묶음의 정서를 잡는다. 같은 곡을 사용하는 다음 컷·장에서는 처음부터 다시 틀지 않는다. 잠깐의 말다툼이나 웃음 때문에 곡을 교체하지 않는다.
- **환경음:** 실제 장소와 날씨를 들려준다. 야외에서 실내로 들어가면 바람·새소리를 줄이거나 멈춘다. 서로 다른 계절·시간을 건너뛰었다면 같은 파일을 쓰더라도 그때는 새 구간으로 다룬다.
- **효과음:** 문이 실제로 열리는 순간, 옷을 꺼내는 순간처럼 명확한 사건에 한 번 사용한다. 인물의 대사 한 줄마다 소리를 덧붙이지 않는다. 이미 일어난 일을 회상하는 문장에는 현재 사건처럼 효과음을 재생하지 않는다.
- **선택지:** 기존 음악과 환경음을 유지한다. 선택을 생각하는 시간을 재촉하는 징글·초시계 소리는 넣지 않는다. 선택 직후에도 분위기가 같으면 같은 곡을 이어 쓴다.
- **의도적 무음:** 고백, 망설임, 돌이킬 수 없는 행동처럼 말과 침묵 자체가 중요한 곳은 소리를 덜어 낸다.
- **미확보 — 비워두기:** 정확한 소리가 없거나 적합한 확보본을 아직 고르지 못했다면 그 칸을 비운다. 유사한 재료의 충격음이나 다른 장소의 녹음으로 억지로 대체하지 않는다.

여러 장을 묶은 아래 항목은 ‘그 장들에 같은 곡을 쓸 수 있다’는 뜻이다. 분기 작품의 장 목록을 위에서 아래로 모두 재생하라는 뜻은 아니다. 실제로 선택해 방문하는 경로에서만 이어 쓴다. 같은 곡이라도 시간 경과·실내외 이동·침묵 구간을 건너 무조건 계속 재생하지 않는다.

화면 전환과 소리 전환은 따로 생각한다. 음악을 바꿀 이유가 있는 경우에만 약 2~3초 동안 부드럽게 넘기는 것을 시작안으로 삼는다. 읽기 속도가 사람마다 다르므로 몇 초 후 자동으로 다음 음악을 틀도록 고정하지 않는다. 반복 연결부와 대사 간섭은 실제 재생 환경에서 청취한 뒤 결정한다.

## 3. 흥부전

참고: [원작 읽기 대본](https://github.com/LUCKYBRIDGE/story-maker/blob/18da4fc5bd4bf2a9080b32903d31f1aacdd24a0b/app/story-classic-heungbu.ts), [놀스토리 각색 대본](https://github.com/LUCKYBRIDGE/story-maker/blob/18da4fc5bd4bf2a9080b32903d31f1aacdd24a0b/app/story-heungbu.seed.json).

### 3-1. 원작 — 흥부전

**① ‘쫓겨난 흥부’에서 ‘빈 쌀독’까지: 곤궁한 생활을 하나의 구간으로 묶기.**

첫 소개에는 M2를 낮게 두는 후보를 제안한다. 부모의 죽음과 재산 다툼에 들어가면 곡을 바꾸기보다 M2를 줄여 무음으로 넘어가고, 쫓겨난 뒤의 생활과 도움 요청까지 무음을 유지해도 좋다. 바깥 이동에만 E1을 고려하고 집 안 대화에서는 멈춘다. 실제 문이 닫히는 묘사가 없는 컷에 S2를 임의로 넣지 않는다. 품팔이·장작 패기·빈 쌀독의 구체적인 소리는 **미확보 — 비워두기**.

**② ‘다친 제비’의 봄과 돌봄: M3를 여러 컷에 유지하기.**

처마의 제비 가족을 보고 치료하는 대화까지 M3를 조용히 이어 쓴다. 낮의 마당에 E2를 작게 둘 수 있지만 ‘제비의 울음’으로 설명하지 않는다. 제비가 떨어지거나 다리를 다치는 순간에는 충격음을 넣지 않는다. 가을의 떠남, 겨울 경과, 이듬해 봄은 시간이 다른 구간이므로 새소리를 끊었다가 봄에 다시 시작한다. 제비 전용 울음·날갯짓·박씨 떨어지는 소리는 **미확보 — 비워두기**.

**③ ‘흥부가 박을 타다’: 박마다 다른 음악을 넣지 않기.**

가족이 박을 준비하는 동안 앞의 M3를 이어 쓸 수 있다. 첫 박에서 곡식이 나오는 순간에도 새 징글 대신 같은 곡의 음량을 조금 올리는 정도로 비교한다. 이후 여러 박, 가족의 안도와 나눔까지 같은 곡을 유지한다. 재물 가운데 실제 동전이 보이는 연출을 선택했다면 S4를 한 번 고려하되, 대본의 ‘귀한 물건’ 전체를 동전 소리로 표현하지 않는다. 박 톱질·갈라짐·곡식 쏟아짐은 **미확보 — 비워두기**.

**④ ‘놀부와 제비’에서 ‘놀부가 박을 타다’: 욕심과 소동에 맞는 곡은 비워두기.**

흥부 집을 방문하는 동안에는 기존 M3를 낮게 유지할 수 있다. 놀부가 제비를 일부러 다치게 하려는 구간부터 음악을 줄인다. 심리적 불편함과 박 속의 소동에 맞는 음악은 이번 후보에서 **적합본 미선정 — 비워두기**로 둔다. 빠른 추격 음악을 대화 전체에 얹지 않는다. 제비 상해, 군중 소동, 살림 파괴를 일반 타격음·천둥으로 대신하지 않는다. 마지막 주저앉는 컷은 의도적 무음.

**⑤ ‘다시 만난 형제’: 후회에서 화해까지 한 곡으로 천천히 이어가기.**

처음 찾아가 말을 꺼내는 구간은 무음으로 시작한다. 잘못을 인정한 뒤 서로 돕기로 하는 대화에는 M2를 조용히 시작하고, 서로의 집을 오가는 마지막 해설까지 유지한다. 고백마다 감동 효과음이나 엔딩 징글을 붙이지 않는다.

### 3-2. 놀스토리 — 흥부와 놀부, 서로의 몫

**① ‘반쪽짜리 떡’부터 ‘곳간 앞의 두 형제’까지: M1을 관계의 도입 음악으로 유지.**

어린 형제가 떡을 나누고 티격태격하는 컷을 M1 한 곡으로 묶는다. 다음 장의 성장과 흉년은 시간이 지난 구간이지만, 비슷한 음악을 이어 쓰고 싶다면 같은 M1을 낮춰 재사용한다. 곳간의 논쟁에서는 볼륨을 낮출 뿐 다른 긴장곡으로 바꾸지 않는다. 떡 나누기·곡식 자루 운반 소리는 **미확보 — 비워두기**.

**② ‘각자의 몫’부터 ‘겨울 문턱’의 첫 선택까지: 갈등과 생계 대화는 소리 덜기.**

부모의 죽음이 서술되는 ‘각자의 몫’ 7컷 전후부터 M1을 줄여 무음으로 넘어간다. 재산 분배와 겨울의 빌림 조건을 상의하는 긴 대화는 무음으로 묶어도 좋다. ‘겨울 문턱’에서 과거 큰비를 언급하는 7컷에는 현재 비가 내리는 것처럼 E4를 틀지 않는다. 야외 방문의 E1도 가족이 실내에서 의논할 때는 멈춘다. 첫 선택에 성공·실패 징글을 넣지 않는다.

**③ ‘빌린 곡식’ 또는 ‘빈손의 겨울’에서 ‘제비가 머문 집’까지: 선택 결과를 채점하지 않는 M2.**

어느 길을 골랐든 가족과 이웃의 생활을 보여 주는 구간에는 같은 M2를 제안한다. 도움을 빌린 길만 밝은 음악, 거절한 길만 어두운 음악으로 구분하지 않는다. 봄의 제비 돌봄으로 이어질 때도 M2를 그대로 사용한다. E2는 실제 낮의 마당에만 작게 더한다. 헝겊을 가져와 다루는 연출이 있을 때 S3를 한 번 고려한다. 겨울 노동·지붕 수리·다친 제비 소리는 **미확보 — 비워두기**.

**④ ‘박이 열리던 날’: 기쁨에서 가족의 의논까지 M2 유지.**

박의 재물이 쏟아진다고 곧바로 축제곡으로 바꾸지 않는다. 가족이 무엇에 쓸지 의논하고 이웃에게 고마움을 돌려주는 컷까지 M2를 이어 쓴다. 대본상 톱질(4컷)과 박의 갈라짐(6컷)은 **미확보 — 비워두기**. 첫 박의 등장마다 별도 징글을 반복하지 않는다.

**⑤ ‘놀부에게 생긴 불편한 마음’과 ‘같아 보이는 방법’: 같은 불편함을 음악 교체 없이 표현.**

방문 초반에는 앞의 M2를 낮게 유지하다가 질투와 자기합리화가 드러나는 부분에서 줄여 무음으로 넘긴다. 두 장의 속내와 제비를 잡는 망설임은 같은 무음 구간으로 묶는다. 새 상해 장면에 뼈 소리·충격음을 넣지 않는다. 맞는 심리 긴장음은 **적합본 미선정 — 비워두기**.

**⑥ ‘다른 박’: 대본의 물과 바람도 기존 자연음을 억지로 대체하지 않기.**

깨진 항아리·솥·도깨비가 나오는 소동은 해당 사건에 맞는 확보본을 아직 고르지 못했으므로 비워 둔다. 15컷의 ‘거센 물과 바람’에는 비·천둥 녹음 E5나 작은 강 E3를 대신 넣지 않는다. 여기에는 재앙의 물 쏟아짐·강풍·집 붕괴가 필요하므로 **미확보 — 비워두기**. 16~19컷의 주저앉음과 돌아봄은 의도적 무음.

**⑦ ‘뒤바뀐 문 앞’에서 두 결말까지: M2로 질문을 잇고 M3로 생활을 마무리.**

가족이 도움의 방법을 의논하는 동안 무음을 유지하거나 M2를 아주 낮게 시작한다. 마지막 선택과 직후 대화에서도 그대로 이어 쓴다. ‘함께 짓는 밭’과 ‘두 집 사이의 길’은 서로 다른 결말이지만 둘 다 생활을 다시 만드는 이야기이므로 M3를 공통 후보로 둔다. 결말 선택 직후 곧바로 승리 음악을 넣지 않는다. 일상이 정착하는 시간 경과 뒤 M3를 시작하는 편이 좋다. ‘두 집 사이의 길’ 11컷의 큰비는 실제 당시의 장면을 보여 줄 때만 E4를 짧게 고려하고, 다음 날 대화·마지막 식사까지 비 소리를 끌고 가지 않는다.

## 4. 옹고집전

참고: [원작 읽기 대본](https://github.com/LUCKYBRIDGE/story-maker/blob/18da4fc5bd4bf2a9080b32903d31f1aacdd24a0b/app/story-classic-onggojib.ts), [놀스토리 각색 자료](https://github.com/LUCKYBRIDGE/story-maker/blob/18da4fc5bd4bf2a9080b32903d31f1aacdd24a0b/app/story-examples.generated.json)의 두 번째 작품.

### 4-1. 원작 — 옹고집전

**① ‘닫힌 대문’에서 승려를 내쫓는 장면까지: 인색함을 우스운 음악으로 처리하지 않기.**

음악은 의도적 무음을 첫 안으로 둔다. 가난한 사람과 어머니에게 매정하게 구는 대사에 경쾌한 장터곡이나 오류음을 넣지 않는다. 대본에 실제 곳간 문을 잠그는 사건이 있으나 S2는 문 닫기 소리일 뿐 빗장·잠금 소리가 아니다. 잠금 소리는 **적합본 미선정 — 비워두기**. 실내 어머니 방에 야외 바람을 그대로 얹지 않는다.

**② ‘또 하나의 옹고집’의 도술부터 ‘두 옹고집’까지: M5로 기묘한 사건을 묶기.**

도승이 짚 인형을 만들고 변화를 일으키는 부분에서 M5를 조용히 시작한다. 가짜가 집으로 들어가고 진짜와 마주치는 다음 장까지 같은 음악을 유지하는 후보로 둔다. 고함이 커지면 음악을 낮춘다. 변신·주문·짚 인형의 움직임 소리는 **미확보 — 비워두기**. 문이 실제로 열리는 묘사에만 S1을 한 번 고려한다.

**③ ‘누가 진짜인가’: 판정 대화 전체는 무음 또는 앞 곡의 낮은 유지.**

족보·전답·증언을 확인할 때마다 음악을 바꾸지 않는다. M5가 대화를 방해하면 장 초입에서 줄여 무음으로 넘어가고 판정까지 그대로 둔다. 책장을 실제로 넘기는 연출을 추가하는 경우에만 S5가 후보이며, 문서가 어디 있는지 말만 하는 컷에는 넣지 않는다. 관아의 군중·포졸 소리는 **미확보 — 비워두기**.

**④ ‘쫓겨난 옹고집’에서 도승 앞의 돌아봄까지: M4 한 곡 또는 침묵.**

분노가 잦아들고 자신이 한 말을 되돌아보는 구간부터 M4를 낮게 고려한다. 산으로 찾아가 사과하는 다음 장의 초반까지 같은 곡을 유지할 수 있다. 바깥 처마·산길에는 E1을 작은 후보로 두되 실내·도승과의 대화에서는 줄인다. 대문 두드리기·허기·눈길 소리는 **미확보 — 비워두기**. 후회를 음악이 과하게 지시하면 M4도 비운다.

**⑤ ‘다시 열린 대문’: 변신 해제 뒤 달라진 생활에 M2.**

부적을 보여 주는 순간의 도술 효과음은 비워 둔다. 어머니의 방을 돌보고 곳간을 열기 시작하는 뒤쪽부터 M2로 전환하고, 여러 계절 동안 달라진 행동을 보여 주는 마지막까지 유지한다. 한 번의 화려한 성공 징글로 속죄가 끝난 듯 처리하지 않는다.

### 4-2. 놀스토리 — 옹고집전: 옹고집의 속죄

이 작품은 ‘아내의 대답’ 이후 장작·품삯·짚신을 둘러싼 장면, 관아 판결, 돌아온 집에서의 작은 선택들이 여러 경로로 나뉜다. 똑같이 ‘돌아온 뒤’라는 제목을 가진 장도 내용이 다르다. 장 제목만 보고 소리를 자동 배정하지 말고 실제 사건을 읽는다.

**① 겨울의 밥상·대문 밖 사내·약속한 노동: 실내는 무음, 바깥만 작은 E1.**

‘아내의 대답’과 `part1-court-cruelty-*` 경로의 초반은 같은 차갑고 불편한 생활 구간으로 본다. 야외에서 장작을 패거나 대문 밖에 머무는 동안만 E1을 낮게 고려한다. 눈보라의 정확한 환경음, 젖은 장작 도끼질, 그릇 건네기는 **미확보 — 비워두기**. 엽전이 실제로 굴러오는 장면에는 S4를 한 번 후보로 두지만 눈 위에 떨어지는 소리에 맞지 않으면 비운다.

**② 같은 얼굴의 귀환부터 관아의 질문·판결까지: M5 하나로 묶거나 무음.**

다정해진 같은 얼굴의 사내가 들어오는 구간에서 M5를 아주 낮게 시작하는 후보를 둔다. 두 옹고집이 맞서고 부인이 판단을 요구받는 관아 구간까지 같은 곡을 유지할 수 있다. 아이의 두려움이 드러나면 음량을 줄인다. ‘오래 함께 산 남편’과 ‘아이를 감싸 준 사람’ 중 누구를 택하든 선택 직후 축하·실패음을 넣지 않는다. 관아의 고함·포졸 제압 소리는 비워 둔다.

**③ ‘돌아온 옹고집’과 ‘되풀이된 판정’: 안도 음악으로 섣불리 결론 내리지 않기.**

집을 되찾아도 아이들이 말을 아끼고 또다시 판정으로 돌아가는 경로이므로 M2를 곧바로 깔지 않는다. 앞의 M5를 줄여 무음으로 넘어가고, 집과 관아의 반복을 무음으로 묶는 안을 제안한다. 같은 판결이 반복된다고 매번 새로운 긴장곡을 넣지 않는다.

**④ ‘쫓겨난 옹고집’: 긴 한 장 안에서도 장소가 바뀌는 지점만 구분.**

집을 돌며 거절당하고 눈 속에서 자신이 남에게 했던 일을 겪는 동안 음악은 비워 둔다. 야외 E1을 작은 후보로 유지하되, 눈보라 소리로 단정하지 않는다. 가짜가 시간의 차이와 아내의 도움을 알려 주는 대화에는 환경음을 줄여 말을 들리게 한다. 집 안으로 부축되어 들어가면 E1을 멈춘다. 상처를 돌보는 부분부터 M2를 작게 시작하는 후보로 두고, 보름 뒤 아이가 말을 꺼내는 부분까지 같은 곡을 재사용한다. 시간 경과는 같은 녹음의 무중단 재생을 뜻하지 않는다.

**⑤ ‘돌아온 뒤’의 작은 선택들: 같은 생활 음악을 지키되 잘못에 징글을 붙이지 않기.**

아이의 이야기를 듣는 `b-meal-act`, 품삯 약속을 지키는 `b-vase-care`, 말을 바로잡는 `b-vase-stick` 등은 M2를 공통 후보로 둔다. 아이를 무시하는 `b-meal-slip`에서는 기존 M2를 줄여 침묵을 드러내되, 오류음으로 ‘오답’ 처리하지 않는다. 이후의 선택들이 같은 생활 흐름이면 새 곡을 계속 추가하지 않는다. 실제 품삯을 건네는 연출이 있을 때만 S4를 한 번 고려한다.

**⑥ ‘갈라진 순간’: 보이지도 들리지도 않는 고립을 소리의 감소로 표현.**

`b-fake-warning`에서 마당이 갈라지고 사람들이 진짜 옹고집을 보거나 듣지 못하는 순간에는 앞의 M2를 줄여 무음으로 넘어가는 안을 제안한다. 대본이 ‘대문을 두드렸다. 소리는 나지 않았다’고 명시하는 부분에는 **문 두드리기 효과음을 넣지 않는다**. 문 안쪽의 빗장 소리는 별개의 사건이지만 적합본을 아직 고르지 못했으므로 비워 둔다. 땅의 균열·환영 등장 소리도 미확보로 남긴다.

**⑦ ‘옹고집의 고백’에서 봄의 열린 대문까지: 고백은 비우고 생활 변화에 M2.**

늦은 밤 잘못을 말하는 구간은 무음으로 둔다. ‘미안하오’ 다음 즉시 성공 징글을 넣지 않는다. 부인이 두려움을 말하고 다시 믿어 보고 싶다고 하는 대화도 끝까지 기다린다. 봄날 아침 아이들과 대문을 여는 마지막 부분부터 M2를 낮게 시작하고 마무리까지 유지하는 후보로 둔다. 봄의 야외가 보이면 E2를 작게 고려하고 실내 밥상에서는 줄인다.

## 5. 별주부전

참고: [원작 읽기 대본](https://github.com/LUCKYBRIDGE/story-maker/blob/18da4fc5bd4bf2a9080b32903d31f1aacdd24a0b/app/story-classic-readings.ts), [놀스토리 각색 자료](https://github.com/LUCKYBRIDGE/story-maker/blob/18da4fc5bd4bf2a9080b32903d31f1aacdd24a0b/app/story-examples.generated.json)의 첫 번째 작품.

### 5-1. 원작 — 별주부전

**① ‘용궁에 닥친 근심’: 용궁과 병세를 위한 음원은 비워두기.**

잔잔한 일상 음악을 병든 용왕의 근심에 억지로 넣지 않는다. 궁중·병세에 맞는 음악은 **적합본 미선정 — 비워두기**. 바닷속 환경음·용왕의 기침·궁중 웅성임은 미확보로 둔다. E3 강물 소리로 수중 용궁을 표현하지 않는다.

**② ‘육지에서 만난 토끼’: 야외의 E1, 필요하면 M3.**

육지에 올라 들판에서 토끼와 이야기하는 구간은 E1을 낮게 이어 쓴다. 대화의 표면적인 평온함에 M3를 작게 둘 수 있지만, 유혹의 말을 음악으로 낭만화하지 않는지 청취 확인한다. 각 대사마다 바꾸지 않는다. 처음 바다를 헤엄쳐 오는 부분은 파도 미확보이므로 비워 두고, 육지에 도착한 뒤 E1을 시작한다.

**③ ‘바닷속 용궁으로’의 이동과 발견: M5로 시각적인 신비만 보태기.**

M5를 수중 풍경을 바라보는 구간의 후보로 둔다. 바다로 들어가는 발·물보라·수중 환경음은 모두 미확보로 비운다. 강물이나 비 소리를 대신 사용하지 않는다. 대전에 들어가 용왕이 붙잡으라고 명령하는 마지막 컷부터 M5를 줄인다.

**④ ‘토끼가 낸 꾀’에서 탈출 결정까지: 말을 듣는 긴 구간은 무음.**

포위와 간을 두고 왔다는 말, 용왕의 판단을 의도적 무음으로 묶는다. 빠른 추격곡은 실제 추격이 없는 긴 협상에 넣지 않는다. 심장박동·포위·밧줄 소리는 미확보로 비워 둔다.

**⑤ ‘다시 밟은 육지’: 도착 뒤 M3를 낮게 되돌리기.**

바다를 건너는 동안 환경음은 비워 둔다. 육지에 도착해 토끼가 뛰어내리고 꾀를 밝힌 뒤 M3를 낮게 시작해 마지막 해설까지 유지한다. E1은 야외에만 사용한다. 토끼의 도약과 숲속 달리기, 별주부의 입수 소리는 적합본을 고르지 못했으므로 비워 둔다.

### 5-2. 놀스토리 — 별주부전

이 각색은 자라의 시점에서 은혜·거짓말·생명의 무게를 다루며 세 갈래 결말이 있다. 살아남은 왕이나 풀려난 토끼를 곧바로 ‘성공’ 음악으로 평가하지 않는다.

**① ‘1막: 용궁 대청’의 명령과 기억: 현재는 무음, 구조 기억만 M5 후보.**

용왕의 병과 명령을 듣는 1~24컷은 무음을 기본으로 둔다. 처방책을 실제로 넘기는 5컷에는 S5를 한 번 고려한다. 큰비에 떠내려왔던 기억인 25~34컷은 M5를 낮게 시작해 은혜의 기억으로 묶을 수 있다. 이 기억에 맞는 홍수·입수·수중 소리는 미확보이므로 비워 둔다. 35컷에서 현재 대청으로 돌아오면 M5를 줄이고, 토끼에게 숨기라는 명령과 내적 질문까지 무음을 유지한다.

**② 육지 도착부터 두 가지 첫마디까지: 같은 E1로 선택 전후 이어 쓰기.**

‘1막’ 50컷부터 겨울 육지의 바람이 명시된다. 이때 E1을 작게 시작하고, ‘첫마디: 용궁 잔치’ 또는 ‘첫마디: 도움 요청’의 대화까지 같은 환경음을 유지한다. 첫마디 선택 때 곡을 바꾸거나 웃음·확인음을 넣지 않는다. 겨울의 바닷가 파도는 미확보로 비운다.

**③ ‘바닷속 길’: M5 한 곡으로 경이로움과 불편함을 함께 두기.**

입수하면 E1을 멈춘다. 은빛 물고기와 산호를 보는 동안 M5를 낮게 유지하는 후보로 둔다. 자라가 토끼의 무게와 숨긴 사실을 떠올릴 때는 같은 곡의 볼륨을 낮추고, 다른 죄책감 음악으로 바로 바꾸지 않는다. 수중 물살과 등에 탄 토끼의 숨소리는 미확보로 비워 둔다.

**④ ‘2막: 초대가 함정으로 바뀌는 순간’: 함정·협상·선택을 한 무음 구간으로.**

용궁에 도착하면 M5를 줄여 무음으로 넘긴다. 호위의 등장, 토끼의 꾀, 자라에게 묻는 용왕, 두 번째 선택까지 그대로 유지한다. 큰 나무문 S1을 수중 ‘물문’의 소리로 사용하지 않는다. 무장 호위·그물·밧줄과 조용한 궁중 긴장 음악은 적합본 미선정으로 비운다.

**⑤ ‘진실을 말한 자라’: 승리 음악 없이 빈자리를 남기기.**

토끼의 말이 거짓이라고 밝히는 대화와 그 결과는 무음으로 둔다. 왕과 용궁이 평화를 되찾아도 비어 있는 방석을 보는 마지막 해설에는 축하곡을 넣지 않는다. M4는 나중에 청취 비교할 회상 후보로만 남기고, 현재 첫 안에서는 비워 둔다. 토끼에게 일어난 일을 과장하는 신체 효과음은 넣지 않는다.

**⑥ ‘확인하러 가겠다는 말’에서 ‘3막: 육지 모래톱’까지: 육지에 도착할 때만 환경 변화.**

용왕에게 말하고 바다를 건너는 동안은 앞의 무음을 유지한다. 바닷속 환경음은 비워 둔다. 새벽 모래톱에 도착한 뒤에만 E1을 작게 시작하고, 토끼와 자라의 대화·마지막 선택까지 같은 소리를 이어 쓴다. 파도와 모래 위 발소리는 미확보·적합본 미선정으로 비워 둔다. 선택지가 나왔다고 새로운 음악을 틀지 않는다.

**⑦ ‘돌아가지 않은 길’: 강에 도착한 뒤 E3, 마지막 돌아봄에는 M4 후보.**

바다를 바라보는 초반은 앞의 E1을 유지하고 파도 칸은 비워 둔다. 이후 실제 강가·강물에서 살아가는 장면으로 바뀌면 E1을 줄이고 E3를 낮게 고려한다. 강의 녹음이라는 이유로 수중에 잠긴 자라가 듣는 소리로 단정하지 않는다. 마지막 해설에는 M4를 작게 더할 수 있지만, 안도와 무거움이 함께 남는 결말을 밝은 성공곡으로 정리하지 않는다.

**⑧ ‘돌아온 자라’: 고백과 징표를 돌려주는 대화는 끝까지 무음.**

바다로 돌아가 용왕 앞에서 고백하는 구간은 E1을 멈추고 무음으로 둔다. 징표를 돌려주는 순간에 보상·실패음을 넣지 않는다. 멀리 울리는 낮고 긴 종소리는 대본에 명시되지만 알림용 징글로 대신하지 않고 **미확보 — 비워두기**. 마지막 강에서의 삶에는 ⑦과 같은 E3·M4 후보를 재사용한다. 두 결말에 불필요하게 다른 곡을 추가하지 않는다.

### 6-1. 원작 — 선녀와 나무꾼

**① ‘사슴의 보은’: 낮의 산에서는 E2 하나를 낮게 유지.**

숲의 평온함과 사슴을 숨겨 주는 대화에 E2를 작은 후보로 둔다. 사냥꾼이 나타났다고 대화 전체를 추격 음악으로 바꾸지 않는다. 위험을 드러내는 순간에는 E2의 음량을 줄일 수 있다. 나무 베기·사슴의 발소리·사냥꾼의 추격 발소리는 적합본 미선정으로 비워 둔다. 사슴이 알려 주는 방법과 금기를 축하 징글로 긍정하지 않는다.

**② ‘연못의 날개옷’: 선녀의 등장에는 M5, 옷을 잃은 곤란함에는 음악 덜기.**

기다리는 낮의 숲에는 앞의 E2를 이어 쓰고, 하늘이 밝아지며 선녀들이 내려오는 구간부터 M5를 작게 고려한다. 정적인 연못에 흐르는 강 E3를 넣지 않는다. 날개옷을 실제로 집어 드는 순간의 S3는 후보지만 숨겨 놓는 행동에 마법 성공음을 넣지 않는다. 하늘로 돌아가지 못한 선녀를 보여 줄 때 M5를 줄여 무음으로 넘긴다. 하강·목욕 물소리·비행은 미확보로 비운다.

**③ ‘다시 나타난 날개옷’에서 ‘하늘로 떠난 가족’까지: 생활 음악에서 긴 무음으로.**

집에서 시간이 흐르는 초반에는 M2를 낮게 유지하는 후보를 둔다. 아이가 태어날 때마다 음악을 새로 틀지 않는다. 날개옷을 보여 주는 구간부터 M2를 줄이고, 선녀와 아이들이 떠난 뒤 나무꾼의 그리움까지 무음을 유지한다. 옷을 꺼내는 실제 동작에만 S3를 한 번 고려한다. 아기 울음·날개옷의 마법·비행 소리는 비워 둔다.

**④ ‘두레박 너머 하늘나라’: 올라가는 구간부터 재회까지 M5.**

하늘로 올라가 풍경을 보고 가족을 다시 만나는 구간은 M5 한 곡으로 묶는다. 두레박 줄·물 담기·상승 소리는 미확보로 비워 둔다. 지상 어머니를 그리워하며 새 금기를 듣는 뒤쪽에서는 같은 M5를 낮추고, 다른 모험곡으로 바꾸지 않는다.

**⑤ ‘돌아오지 못한 길’: 귀환·사고·오래된 그리움에 같은 M4 또는 무음.**

어머니를 다시 만나는 부분에는 M4를 낮게 고려한다. 뜨거운 죽이 흐르고 용마에서 떨어지는 순간에는 음악을 잠시 줄이고, 이후 기다림과 가족에 대한 그리움까지 같은 곡을 재사용하는 후보로 둔다. 용마 날갯짓·말발굽·말의 놀람·낙하·죽 흐름 소리는 미확보로 비운다. 수탉의 울음도 E2의 일반 새소리나 합성 새 효과음으로 대신하지 않고 비워 둔다. 수탉으로 마무리하는 해설에 신나는 엔딩 징글을 붙이지 않는다.

### 6-2. 놀스토리 — 선녀와 나무꾼

각색은 폭풍으로 날개옷을 잃은 선녀를 돕는 만남에서 출발하고, 옷을 찾은 뒤 돌려줄지 숨길지, 진실과 상대의 선택을 어떻게 마주할지에 따라 갈라진다. 원작의 사슴·옷 훔치기·수탉 결말을 이 각색에 그대로 붙이지 않는다.

저장소에는 166개의 분기 장이 있으며 `R1-v13`, `R1-v61`처럼 비슷한 장이 여러 경로에 복제되어 있다. 아래에서는 읽기 쉽게 `R1`, `E1-1` 등 `-v숫자` 앞부분을 사용한다. 동일 접두어의 모든 복제본이 완전히 같은 대본이라는 뜻은 아니다. 실제 선택 경로의 문장을 다시 확인한 뒤 적용한다.

**① ‘계곡’의 평온함에서 ‘폭풍’·‘빗속의 하늘길’·첫 도움 선택까지: 날씨가 이어지는 한 구간.**

‘계곡’(P1)의 시작에는 실제 흐르는 물이 보이는 경우 E3를 낮게 고려한다. 비가 거세지는 ‘폭풍’(P2)에서 E3를 줄이고 E5로 바꾼다. ‘빗속의 하늘길’(P3), ‘나무꾼의 등장’(1), ‘어떻게 도울까?’(C1)와 두 반응(C1-A/B)이 여전히 같은 비 속이면 E5를 계속 유지한다. 장마다 천둥 파일을 처음부터 재시작하지 않는다. 음악은 비워 두고 선녀의 곤란함과 도움의 말을 듣게 한다. 파일 안의 천둥이 대사를 가리면 E5를 쓰지 말고 E4 한 종류로 비교한다. 옷이 바람에 날아감·발목 부상·은빛 하늘길 소리는 미확보로 비워 둔다.

**② ‘작은 집’·‘첫 식사’·‘정체’: 실내로 들어오면 폭풍을 정리하고 M2 한 곡.**

문이 닫히는 사건 뒤 E5를 멈추는 것을 첫 안으로 둔다. 창밖 비가 실제로 이어지는 연출을 택한다면 E4를 아주 낮게 고려하되 실내에서 들리는 비에 맞는지 확인한다. 집·음식·정체를 나누는 대화에는 M2를 낮게 시작해 여러 장에 유지한다. 선녀의 말이 어려워지는 순간에는 곡을 바꾸지 않고 음량만 낮춘다. 문을 닫는 동작에는 S2가 후보이며, 식사·그릇·발목 치료 소리는 비워 둔다.

**③ ‘옷을 찾는 날들’·‘한 달 뒤’·계속 찾을지의 선택: 탐색을 한 주제로 묶기.**

대화의 정서가 이어지면 M2를 그대로 재사용한다. 낮의 숲을 찾을 때 E2를 작은 후보로 더하고 집으로 돌아오면 멈춘다. 계속 찾는 길과 생활을 병행하는 길을 성공·실패 음악으로 구분하지 않는다. 젖은 장작·진흙·가지·산길 발소리 등은 적합본 미선정으로 비워 둔다.

**④ ‘첫눈’·‘서로의 생활’·‘마음을 확인하다’·‘선녀의 선택’·‘약속’·‘평범한 부부’: M2를 가장 오래 유지하는 일상 묶음.**

이 구간에서는 짧은 웃음이나 마음을 확인하는 대사마다 음악을 바꾸지 않는다. M2 한 곡을 중심으로 두고, 새로운 날에는 같은 곡을 다시 사용할 수 있다. 눈이 오는 장면에는 비 소리나 천둥을 넣지 않는다. 실내에서는 새·강·바람을 비워 둔다. 눈·생활 소음·바느질·그릇·씨앗 다루기는 미확보·적합본 미선정으로 둔다.

**⑤ ‘기러기’·‘선녀의 그리움 앞에서’와 두 반응: 그리움을 새 음악으로 몰아가지 않기.**

기존 M2를 낮춰 이어 가거나 잠시 무음으로 둔다. 선녀의 고향 그리움을 현재 삶의 실패처럼 표시하지 않는다. 기러기 떼의 울음은 E2나 합성 새 소리로 대신하지 않고 **미확보 — 비워두기**. 두 선택의 반응 뒤 생활 분위기가 이어지면 같은 M2를 유지한다.

**⑥ ‘두 번째 폭풍’과 ‘선녀옷을 어떻게 할까?’: 앞의 폭풍 파일을 재사용.**

14장의 1컷은 밤의 실제 큰비이므로 E5를 다시 사용하는 후보로 둔다. 첫 폭풍과 같은 파일을 쓰되, 계절과 사건이 다른 새 구간이므로 그때 다시 시작할 수 있다. 2컷부터는 다음 날이므로 폭풍을 멈춘다. 옷의 발견과 뒤의 선택까지 비를 계속 틀지 않는다. 8컷의 맑은 계곡에는 실제 흐르는 물이 보이는 경우에만 E3를 작게 고려한다. 천둥이 중요한 대사를 덮으면 E4로 비교한다. 옷이 발견되는 순간에 보물 획득 징글을 넣지 않는다. 14컷의 첫 폭풍 설명은 회상이므로 현재 폭풍을 다시 시작하지 않는다.

**⑦ 옷을 돌려주는 길(R1~R4), 이튿날 고백(HA1~HA2): M2 또는 무음으로 대화 잇기.**

‘보자기’에서 S3를 실제로 펼치는 한 순간에만 고려한다. ‘당신 것이니까’와 이후 선녀의 고민에는 M2를 아주 낮게 재사용하거나 무음으로 둔다. 장이 짧게 나뉘어 있어도 매번 새 곡을 넣지 않는다. ‘선녀의 선택을 어떻게 마주할까?’(C5R)에서도 그대로 유지한다. 늦게 돌려준 경우 선녀가 혼자 있을 시간을 요구하는 대화에는 M2를 줄여 공간을 남긴다.

**⑧ 숨기는 길(H1~H3, HB1~HB3)과 ‘진실을 말할까?’: 불편함은 무음으로 오래 유지.**

‘장작 창고’에서 마음속으로 미루는 부분부터 음악을 줄인다. 다음 날, 둘째 날, 셋째 날, 직접 묻는 선녀의 대화까지 같은 무음을 이어 쓴다. 날마다 긴장곡을 바꾸거나 초시계 소리로 선택을 재촉하지 않는다. 옷을 실제로 숨기는 동작에는 S3를 한 번 고려할 수 있지만, 자기 속내를 말하는 문장에는 넣지 않는다. 창고 궤짝·장롱에 맞는 소리는 적합본 미선정으로 비운다.

**⑨ 존중하고 헤어지는 결말(E1-1~E1-4): 떠남은 M6, 이후 삶은 무음 또는 M7 후보.**

‘서로 확인하다’는 앞의 대화 음악 또는 무음을 유지한다. 실제 보름밤 하늘길이 열리는 ‘올라가는 날’에만 M6를 낮게 시작해 선녀가 떠나는 장면까지 이어 쓴다. 상승·하늘길 소리는 비워 둔다. 이후 ‘남은 마당’과 ‘존중과 이별’은 다른 시간·장소이므로 M6를 멈춘다. 두 사람이 각자의 하루를 시작하는 마무리에는 M7를 낮게 고려하되, 이별을 승리처럼 들리게 하면 무음을 택한다.

**⑩ 지상에 남기로 한 결말(E2-1~E2-4): M2로 이어지는 선택 이후의 일상.**

‘남고 싶은 삶’에서 기존 M2를 유지하고, 마지막 보름밤에도 새로운 로맨스곡을 반드시 추가하지 않는다. 하늘길을 바라보는 부분에 M6를 꼭 넣기보다 M2를 낮추는 안을 먼저 비교한다. 겨울과 그 이후의 생활·약속까지 M2를 같은 주제로 재사용한다. 날개옷과 머리끈을 실제로 정리하는 순간에만 S3를 한 번 고려한다. 성공 징글은 넣지 않는다.

**⑪ 늦은 고백과 떠남(E3-1~E3-5, C6C-A/B): 대화는 무음, 하늘길에만 앞의 M6 재사용.**

옷을 꺼내 사실을 말하고 선녀가 거리를 두며 떠날 준비를 하는 동안은 무음으로 묶는다. 마지막으로 무엇을 말할지 고르는 순간에도 유지한다. 실제 하늘로 가는 장면에서는 ⑨와 같은 M6를 재사용할 수 있다. 몇 계절 뒤 ‘늦은 고백과 다시 내린 비’는 음악을 무음으로 둔다. 1~2컷의 회고와 출발에는 비를 시작하지 않고, 3컷부터 현재 비바람이 명시된 저녁이므로 E4를 낮게 고려해 만남 대화까지 유지한다. 천둥은 따로 추가하지 않는다.

**⑫ 거짓말·옷의 발견·마주함·지상으로 떠나는 결말(E4-1~E4-9, C6L-A/B): 긴 무음으로 관계의 거리 남기기.**

직접적인 거짓말, 더 깊이 숨기기, 달빛 속 옷의 발견, 마주하는 대화, 다음 날 식탁과 짐을 챙기는 장까지 음악 없이 묶는다. ‘문을 나서다’는 하늘로 비행하는 결말이 아니라 마을로 내려가는 길이므로 M6를 재사용하지 않는다. 마지막 ‘영원히 닫힌 문’에서 닫는 것은 장롱 문이므로 일반 방문 닫기 S2를 자동 배정하지 않고 적합본 미선정으로 비워 둔다. 이후에도 무음을 유지한다. 잘못을 표시하는 오류음이나 비극을 과장하는 추격곡은 넣지 않는다.

## 7. 비워 둘 소리와 추가 확보 우선순위

아래는 이번 제안에서 남긴 빈칸이다. 소리가 있어야 작품이 완성된다는 뜻은 아니다. 대사와 그림만으로 충분한 구간은 계속 비워 둘 수 있다. 일반 효과음 묶음에 비슷한 이름이 있더라도, 장면에 맞는 소리라고 확인하지 않은 것은 미선정으로 남긴다.

| 필요한 소리 | 필요한 구간 | 현재 처리 |
|---|---|---|
| 잔잔한 해변 파도·바닷속 환경음·입수 | 별주부전 원작·각색의 바다 이동과 용궁 | 미확보 — 강물·비로 대체하지 않음 |
| 박 톱질·박이 갈라짐·곡식 쏟아짐 | 흥부전 원작·각색의 박 | 미확보 — 나무 충격·무기 소리로 대체하지 않음 |
| 눈보라·눈길·실내 문틈 바람 | 옹고집 각색과 겨울 장면 | 적합본 미선정 — 야외 일반 바람은 제한적 후보 |
| 장작 도끼질·지붕 수리·집 붕괴·강한 물 쏟아짐 | 흥부·옹고집의 노동·재앙 | 적합본 미선정 — 일반 충격·작은 강으로 대체하지 않음 |
| 제비·까치·기러기·수탉의 특정 울음·날갯짓 | 각 작품의 명시된 동물 사건 | 미확보 — 공원 새소리는 장소 분위기에만 고려 |
| 정적인 연못·목욕 물소리·두레박 | 선녀와 나무꾼 원작 | 미확보 — 작은 강과 낙차 녹음으로 대체하지 않음 |
| 용마·말발굽·사슴 추격·모래·눈·산길 발걸음 | 원작 선녀·별주부의 이동 | 적합본 미선정 — 일반 발걸음 파일을 자동 배정하지 않음 |
| 관아 웅성임·포졸·수중 물문·빗장·문 두드림 | 옹고집·별주부 | 미확보 또는 적합본 미선정. 옹고집 각색의 ‘소리 없는 두드림’은 의도적 무음 |
| 낮고 긴 종·환영·균열·날개옷 마법·하늘길 | 각색 별주부의 마지막 종, 옹고집·선녀의 초현실 사건 | 미확보 — UI 알림·징글로 대체하지 않음 |
| 국악 도입·절제된 심리 긴장·생활 속 회한 | 전래동화 정서와 긴 갈등 | 적합본 미선정 — 중세풍·빠른 추격곡으로 빈칸을 채우지 않음 |

추가 확보를 한다면 **바다 → 박 톱질·갈라짐 → 겨울·생활 소리 → 특정 새·마법 소리** 순으로 살펴볼 수 있다. 실제로 들어 보고 꼭 필요하다고 판단한 구간부터 확보한다. 이 문서는 추가 다운로드를 지시하거나 새 음원을 확보했다는 기록이 아니다.

## 8. 나중에 실제 작품에 적용할 때

1. 이 제안과 실제 뉴놀스토리 대본의 장면이 같은지 먼저 확인한다. 이름이 같아도 사건이 달라졌으면 제안을 다시 검토한다.
2. 아래 후보 파일을 [청취 화면](../../assets/audio-preview.html)에서 먼저 단독으로 듣는다. 맞지 않으면 다른 파일을 억지로 고르지 말고 비워 둔다.
3. 같은 분위기의 연속 구간에서 한 음악·환경음을 유지하며, 단독 듣기와 함께 듣기를 비교한다. 환경음은 음악보다 작게 시작하고 대사를 가리지 않는지 확인한다.
4. 짧은 장·선택지가 등장해도 재생 위치를 유지하는지, 실내외·날씨·시간 변화에서는 필요한 소리만 바뀌는지 확인한다.
5. 실제 선택한 경로와 반복 연결부를 끝까지 청취한다. 문서의 여러 분기 장을 단일 순서로 적용하지 않는다.
