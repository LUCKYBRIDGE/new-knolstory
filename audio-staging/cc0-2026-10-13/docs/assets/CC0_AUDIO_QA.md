# CC0 음원 확인 기록

2026-10-13. 전체 디코딩과 파일 해시 결과는 `assets/metadata/audio/cc0-validation.json`을 따른다.

- [확인] 라이선스 재점검: 39개 저장본·현재 배포 필드 모두 CC0 단독. 490개 파일의 출처 대응·해시 통과. 동봉 문서 6개에서 조건 충돌 없음. 상세 근거는 [라이선스 분석](CC0_LICENSE_AUDIT.md)에 있다. 선택적 출처 안내 수집 누락 13건은 보충했으며 원래 증거는 보존했다.

- [확인] 작품용 추가 배경음 6곡 및 이후 편집용 83개를 포함해 음원 490개·개별 CC0 배포 페이지 39개 연결을 검사했다. 전체 끝까지 디코딩·해시 검사를 통과했다.
- [확인] 편집용 확장 전 407개 ID·revision·원본/재생 경로·해시·분류와 장·컷 표의 바이트를 보존했다. 신규 83개에 편집용 태그와 별도 목록이 있다. 물 묶음은 실제 파일명 기준 6개 반복 환경음·34개 단발 효과음으로 구분했다.
- [확인] 기존 401개 ID·원본 해시·재생본 해시·버전 경로를 유지했다. 최신 장·컷 표의 모든 범위에 배경음 후보가 있다. 신규 6곡의 장면 적합성·반복 연결 청취는 미확인이다.
- [확인] 기존 음원 비교 도구는 가상 음원 파일과 목록으로 동일 바이트, 같은 이름·다른 바이트, ID 충돌 검출 및 원본·라이선스 보존을 확인했다.
- [확인] 브라우저에서 목록 401개 표시, 검색 결과 1개 표시, 분류와 검색 조합으로 0개 표시, BGM 재생과 정지 동작을 확인했다. 검증 화면은 `audio-preview.png`이다.
- [확인] 시험 재생한 `once_upon_a_time_loop.ogg`는 브라우저 미디어 오류가 없었다.
- [확인] 함께 듣기 화면에서 마을 음악+새소리, 잔잔한 음악+비, 달밤 음악+폭풍우를 각각 동시 재생했다. 두 채널의 재생 시간이 진행되고 미디어 오류가 없는 것을 확인했다.
- [확인] 배경음만/환경음만 듣기는 상대 채널만 음소거하고 두 채널의 시간 진행을 유지했다. 환경음 슬라이더 12%→8%, 조합 전환 시 양쪽 정지, 검색 중 동시 재생 유지, 두 소리 정지를 확인했다. 화면은 `audio-mixer.png`이다.
- [미확인] 위 검증은 재생 기능 확인이다. 실제로 겹쳐 들었을 때의 자연스러움·대사 간섭·반복 연결부에 대한 청취 평가는 아직 기록하지 않았다. 조합의 시작 볼륨을 최종 믹싱 수치로 사용하지 않는다.
- [미확인] 인앱 브라우저는 이 파일의 길이를 62.56초로 표시했으나 FFmpeg와 파일 메타데이터는 57.60초로 일치했다. 실제 개발 브라우저와 Ren'Py에서 표시·재생 길이를 다시 확인해야 한다. 원본이나 재생본을 이 차이에 맞춰 자르지 않았다.
- [미확인] 전체 청취, 반복 연결부, 실제 다른 로컬의 기존 음원 비교는 남아 있다.
