# 상업용 음원 제공처 검토

확인일: 2026-10-10. 이번 사용자 조건은 **무료·상업적 이용 가능**이다. 실제 등록은 개별 파일의 권리·원본·출처 증거와 편집/재생 검증을 갖춘 것에 한한다. 웹사이트 전체를 하나의 라이선스로 취급하지 않는다.

놀스토리의 완성 작품에 음악을 삽입하는 것과 여러 사용자가 고르는 편집 자산으로 음악을 제공하는 것은 권리 범위가 다를 수 있다. 놀스토리가 음원 자료집 서비스인지와 별개로, 공급자가 정한 도구/소스파일/최종 사용자 제공 제한을 확인한다. 사용자가 내보낸 `.knolstory`, Excel, Google Sheets 편집 흐름에서 원본 이름과 출처가 유지되므로, 기본 탑재 자료는 상업 이용뿐 아니라 복사·수정·재제공 제한도 함께 확인한다.

이 조사 당시 기본 목록61개는 등록된 자료 수다. 이후 일괄 제외 판단을 [장면 사용 권리 검토](audio-service-rights.md)로 수정해 현재 CC047개와 장면용 조건부 Pixabay14개를 선택할 수 있다. 이번 CC0 21개의 권리 판정을 이전 Pixabay 등 모든 음원에 대한 공용 재제공 승인으로 확대하지 않는다. 과거 자료의 개별 사용 범위와 공용 편집 제공·파일 반출 범위는 별도로 검토한다.
