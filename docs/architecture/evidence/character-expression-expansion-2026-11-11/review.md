# 네 작품 인물 동작·표정 추가

2026-11-11 사용자 요청에 따른 편집 자료 확장이다. [선정 계획](plan.json)은 추가 전 수량·카탈로그 해시와 부족한 동작/인물의 선정 이유를 소유한다. [생성 기록](generation.json)은 참조 이미지·해시·동작 요청·원본 PNG·실행 WebP·변환 수치를 소유한다.

## 추가 범위와 확인

| 작품 | 새 이미지 | 선정 이유 |
| --- | --- | --- |
| 흥부와 놀부 | 흥부 아내 환영·단호한 설명, 놀부 아내 사과·밥그릇 건네기 | 두 아내는 각각2종뿐이고 실제 손동작 변형이 적었음 |
| 선녀와 나무꾼 | 선녀 설명·위로, 나무꾼 사과·장작 패기 | 서 있는 표정 변형에 비해 구체적인 행동이 부족했음 |
| 별주부전 | 토끼 사과·위로, 자라 감사 인사, 어의 약재 살펴보기 | 상호작용과 진찰을 구분하는 자세 보강 |
| 옹고집전 | 아내 안도·말리기, 어머니 타이르기, 막내 눈물 닦기 | 옹고집 본인의 중복 변형보다 가족·조연의 부족한 표현 우선 |

10개 인물 정체성에16종을 추가했다. 이미지가 많은 작품도 특정 인물의 표현 범위는 적을 수 있어 총수만으로 부족함을 판단하지 않았다. 이 추가로 모든 인물/행동/표정의 조합을 완성했다는 뜻은 아니다.

참조 이미지를 직접 확인하고 동일 인물의 얼굴·나이·머리·복장·신발·화풍을 유지하도록 개별 생성했다. 네 작품의 생성 비교판을 청록색 배경 위에서 확인했으며 손·발·귀·소품과 팔/다리 사이의 투명 여백을 검토했다. 밥의 흰색과 옷·버선·수염은 불투명한 내용으로 유지한다. 모호한 손가락/소품은 실제 선택·재생 화면과 함께 대조하며, 생성 편집이 원본의 픽셀 복제라는 주장은 하지 않는다.

같은800×1200캔버스에서 가로세로 같은 비율로 줄이고 참조 이미지의 발 기준선을 맞췄다. 아이를 어른 높이로 늘리지 않고, 사과하며 숙인 자세와 토끼의 처진 귀는 자연스러운 높이 차이를 유지한다. 원본 PNG는 별도 `assets/source/characters/expressions-v1/`, 실행 WebP는 `apps/web/public/assets/characters/expressions-v1/`에 보관한다.

## 연결·보존 경계

새 ID16개와 검색 메타데이터를 추가한다. 원래433개 카탈로그 행과 순서/해시·기존 원본·제공 작품·개인 원고/저장소는 변경하지 않는다. 새 이미지는 편집에서 이용자가 선택하는 자료이며 기존 작품 컷에 자동으로 넣지 않는다. 같은 인물ID에 연결하고 단일 전신/동작/표정/의상 검색 태그를 제공한다. Ren’Py 경로 검증에는 이번16개의 정확한 경로만 추가하며 임의 폴더·외부 URL은 허용하지 않는다.

`generatedExpressionAsset`는 현행 Git 생성 자료다. 레거시 복원 도구는 구 저장소에서 찾거나 덮어쓰지 않고 현재 해시를 검사한다. 출처/서비스 사용 허가에 정확한 실행 파일 해시와 생성 근거를 추가한다. CC0·제3자용 무제한 자료실 허가로 바꾸지 않는다. API도 같은 카탈로그를 사용하므로 다음 실제 배포에서는 새449개 목록이 API 이미지에도 포함됐는지 확인해야 한다. 이번 로컬 구현은 운영API 갱신·인증 업로드·사이트 배포를 뜻하지 않는다.

## 다른 컴퓨터에서 준비·검사

```sh
pnpm install --frozen-lockfile
python3 -m pip install Pillow==11.3.0 fonttools==4.60.2
python3 scripts/prepare-expression-assets.py
# 실행 WebP가 없는 경우에만 생성 원본에서 같은 해시로 복원한다.
python3 scripts/prepare-expression-assets.py --restore
pnpm runtime:build
pnpm build
pnpm exec playwright test --config tests/character-expressions.playwright.config.ts
```

스크립트는 저장소 상대 경로를 사용하며 기존 수정 파일을 덮어쓰지 않는다. 소스PNG·실행WebP·카탈로그·receipt가 함께 필요하다. SDK·기존 비공개 자료는 [재현 환경](../../reproducible-test-environment.md)을 따른다. 검증 결과·실패 보완·남은 범위는 [체크포인트](checkpoint.json)에 기록한다. 과거 봉인된 배포 runtime-review를 이번 바이트의 승인으로 재사용하지 않는다.
