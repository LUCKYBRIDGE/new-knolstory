# 문장과 실제 기능의 수동 대조

2026-10-19. 금칙어 검색 결과를 검토 근거로 삼지 않고, 편집 담당/읽기 담당의 독립 소스 검토와 주 작업자의 파일·온라인·계약 문서 정독을 합쳤다. 이 기록은 실제 화면을 전부 조작한 사용성 감사가 아니다. 소스 분기·저장 대상·컴포넌트 사용처와 문장 의미를 대조하고, 변경한 동작에는 별도 집중 검사를 실행했다.

| 읽은 대상 | 실제 동작과 다른 문장·구조 | 조치 |
|---|---|---|
| 점수 숫자·이름 입력 | 현재 prop 값을 마지막 파일 저장 값처럼 안내 | 현재 원고에 적용된 값/이름으로 수정 |
| 점수 삭제 제한 | 작품 전체 배열 index를 장 안 컷 번호로 표시 | 실제 장과 cutLabel로 위치 표시. 여러 장의 회귀 검사 추가 |
| 선택지 점수 도구 | 조건 도구가 숨겨져도 조건 설명·접근성 이름 노출, 효과가 없어도 점수 변화 단정 | 표시 조건 노출 여부와 설명/이름을 함께 맞춤. 실제 지정한 변화가 적용된다고 설명 |
| 점수 조건 없음 | 언제나 사용할 수 있다는 불분명한 약속 | 설정한 점수 조건이 없다는 사실만 안내 |
| 함께 보기 | 이미 기본 제공되는 글·배경 기능도 켜라고 안내 | 편집화면 이동과 선택적 기능 켜기를 구분 |
| 선택 이력 조건 | 조건 제거를 모든 갈래로 표현 | 선택 이력 조건 없음. 실제 선택지가 있는 컷부터 재생 안내 |
| 선택 조건 후보 | chapterLabel과 cutLabel에 장 정보 중복 | cutLabel 한 번만 표시 |
| 음향 요약 | 이름 조회 실패를 사용자 파일로 단정, 컷에 미지정된 효과음을 실제 재생 없음으로 단정 | 이름 확인 필요, 이 컷에 지정한 설정임을 명시. 기존 사용자 자료가 없다고 단정하지 않음 |
| 음향 시작/유지 | 실제 독자 경로를 해석하지 않은 편집 요약이 재생 결과처럼 보임 | 재생 시작 설정/종료 컷/이전 설정 사용/현재 소리 계속 재생으로 구분 |
| 빠른 저장 접근성 이름 | 저장 화면에서도 불러오기라고 읽힘 | 실제 실행에 따라 저장/불러오기 구분 |
| 저장 없음 오류 | 직접·자동 저장이 없어도 빠른 저장부터 하라고 안내 | 요청한 종류에 맞는 안내 |
| 읽기 저장 중 | 진행 저장을 화면 저장처럼 설명 | 읽던 진행 저장으로 변경 |
| 서재 복귀 | 브라우저 localStorage를 기기 전체로 표현 | 이 브라우저에 저장한다고 설명 |
| 저장 자료 손상 | 내부 슬롯/형식 이름과 원본 저장이라는 모호한 표현 | 기존 데이터를 지우지 않았으며 현재 읽기를 계속할 수 있다고 안내 |
| 책 시작 도구 | 대본 편집은 실제 전용 글 편집이 아닌 일반 편집 진입 | 편집하기. 작품 정보로 가는 동작도 작품 정보·기획으로 맞춤 |
| 원작 판본 소개 | 교정된 판본을 전래 이야기 원문 그대로인 것처럼 소개 | 원작 판본의 이야기로 설명 |
| 판본 소개 조사 | 놀스토리을 | 선택한 판본을 사용해 조사 오류 제거 |
| 분기조건 용어 | 선택 이력·점수가 모든 도구에 같은 방식으로 적용되는 인상 | 현재 점수 조건/선택 이력 조건의 지원 대상을 각각 명시 |
| 임시 보관 별칭 | 자동 저장을 임시 보관과 동등한 이름으로 노출 | 별칭에서 자동 저장 제거. 읽기 진행 자동 저장은 별도 개념 유지 |
| 저장 계약 첫머리 | 뒤의 실제 계정/API 구현 절과 달리 서버·PostgreSQL 미구현 선언 | 뒤의 날짜별 현재 구현 절·STATUS를 참조하도록 정정 |
| 읽기 설계 | 최신 2비율/3·5줄 뒤에 폐기된 4:3/세 양식/4·6줄을 현재라고 설명 | 이전 설계 구획을 앞당겨 역사 범위와 현재 규칙의 우선순위를 명시 |

## 설명을 바꾸면 안 되는 동작 결함

`packages/runtime-core/src/playback-history.ts`는 방문한 컷의 전체 text를 반환한다. `story-player-menu.tsx`는 `playbackLog(project,playback)` 호출에 현재 컷의 글 페이지 위치를 넘기지 않는다. 현재 컷의 앞 페이지만 읽었어도 뒤쪽 페이지가 지난기록에 보일 수 있다. 실제 브라우저 재현과 Core/호스트 수정은 아직 수행하지 않았다. 이미 읽은 내용만 지난기록에 제공한다는 읽기 계약을 완화하지 않고, 현재 읽기 설계와 단일 실행 계획의 다음 동작 과제로 기록했다.

## 이번 범위에서 유지한 표현과 한계

- 서재 이어읽기는 마지막으로 읽은 장면을 우선한다. 가장 최근 수동 저장으로 바꾸지 않았다.
- 인물 좌/우 역할과 실제 그림의 가로 위치는 별개다. 위치 편집의 데이터 의미를 명칭만으로 합치지 않았다.
- 컷의 음향 요약은 현재 지정값이며 장 기본값·실제 선택 경로에 따른 전체 청취 결과가 아니다.
- 도메인·파일키·사용자 원고와 기존 private 자료를 수정하지 않았다. 오래된 검증 로그와 과거 설계 내용도 삭제하지 않았다.
- 이번 대조가 모든 화면·모든 오류·외부 편집 양식을 수동으로 전수 확인했다는 뜻은 아니다. 서버·물리 기기·전체 접근성·출시 완료로 확대하지 않는다.
