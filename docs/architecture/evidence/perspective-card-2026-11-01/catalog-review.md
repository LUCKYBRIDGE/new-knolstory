# 제공 작품 시점 카드 검토

2026-11-01. 사용자가 올린 옹고집전 화면에서 시점 제목이 화면 위에 작게 모이고, 부인 카드에는 기능명·제목·설명 세 줄이 반복되는 문제를 확인했다. 이번 검토는 실제 `resolveProvidedCatalogStory` 결과로 추출한 8판본의 시점 전환과 전후 본문을 대상으로 한다. 원고·코드 파일은 이 보고서 작성으로 수정하지 않았다.

## 판본별 조사

| 판본 | `perspective-blackout` 수 | 본문의 별도 시점 문구 |
|---|---:|---|
| 선녀와 나무꾼 원작 / 놀스토리 | 0 / 0 | 없음 |
| 흥부전 원작 / 놀스토리 | 0 / 0 | 없음 |
| 옹고집전 원작 / 놀스토리 | 0 / 6 | 아래 카드의 제목과 같은 본문만 존재 |
| 별주부전 원작 / 놀스토리 | 0 / 0 | 없음 |

`presentation.transition.type`과 함께 `text`·`speakerName`의 ‘시점’ 문자열도 조사했다. 제공되는 여덟 판본에서 확인한 시점 안내는 옹고집 놀스토리의 여섯 컷뿐이다. 이를 다른 인물의 일반 대사나 해설까지 확장해 새 시점으로 추론하지 않는다.

## 본문 중복과 내용 보존

여섯 카드 모두 `type:narration`, `speakerName:시점 전환`, `text`가 `transition.title`과 같고 `flow`·`ending`이 없다. Runtime Core의 `compileStoryScene`은 이 조건에서 `transitionOnly:true`를 만든다. 따라서 제목 본문은 편집 원고의 카드 식별을 유지하고, 읽기에서는 시점 전환 뒤 글상자로 같은 제목을 다시 읽는 방식이 아니다.

- 시작 카드 다음은 겨울 저녁 밥상과 아이의 밥알 사건이다.
- 부인 카드 직전에는 두 옹고집과 가족이 관아로 끌려간다. 카드 다음에는 관아 마당에서 두 사람을 가리지 못하는 판정 사건이 이어진다.
- 쫓겨난 옹고집 카드 다음은 관아에서 쫓겨난 옹고집이 자기 집으로 갔다가 문전에서 거절당하는 사건이다.

후속 본문에 ‘지금부터 누구의 시점’이라는 안내가 다시 이어지는 사례는 찾지 못했다. 카드의 제목을 본문에서 지우면 `transitionOnly` 판정이 달라질 수 있으므로 제목 본문·화자·컷 ID를 임의로 삭제하지 않는다.

## 개선 판단

1. **중앙 배치는 공통 Ren’Py 전환 화면에서 고친다.** 여섯 제목은 이미 올바른 `presentation.transition.title`로 전달되고 있다. 개별 작품의 줄바꿈이나 공백으로 위치를 흉내 내면 다른 비율·편집 미리보기에서 다시 깨지므로 renderer의 정렬과 제목 위계를 개선해야 한다.
2. **부인 두 카드의 cue·description은 제거해도 이야기 사실을 잃지 않는다.** ‘부인의 시점’ 자체가 누구를 따라갈지 충분히 말한다. ‘시점 전환’은 기능명 반복이고 설명은 같은 뜻을 풀어 쓴 안내다. 한 제목을 중심으로 연출하는 편이 사용자 요청과 맞는다.
3. **개인 원고 전체에 안내 삭제를 적용하지 않는다.** 작가가 제목·짧은 문구·설명을 의도해 썼을 수 있다. 제공 작품의 정확한 공식 판본에만 새 교정을 연결하고, 직전 공식 판본을 알려진 판본으로 보존하여 기존 공식 보관본을 갱신한다.
4. **효과 종류와 입력 의미를 보존한다.** 자동/확인형, 지속 시간, 읽기 설정, 줄거리 연결과 효과 적용 범위를 이번 미관 개선 때문에 바꾸지 않는다. 긴 제목·설명이 있는 개인 작품은 가로/세로에서 잘리지 않고 확인 버튼과 겹치지 않게 별도로 검증한다.

이 보고서는 원고 구조와 문구의 수동 검토다. 새 중앙 배치가 실제 Ren’Py에서 정확히 보이는지, 화면 비율·동작 줄이기·확인형 입력이 동작하는지는 구현 뒤 별도 화면 검사 근거가 필요하다. 현재 진행 중인 9컷 줄거리 교정과 이전 검증 자료는 보존한다.
