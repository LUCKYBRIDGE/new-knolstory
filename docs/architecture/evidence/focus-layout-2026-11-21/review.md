# 집중 화면 개편 (2026-11-21)

사용자 피드백: 화면마다 정보가 한 페이지에 다 쌓여 있어 지금 읽고 쓰는 작품에 집중하기 어렵다. 상단에도 요소가 많고, 아래로 내리면 계속 무언가가 나온다. 폰·태블릿 글씨도 맞춰야 한다.

## 원칙

1. 화면의 주인공은 지금 읽거나 쓰는 쪽이다. 그 밖의 도구(작품 정보·저장·인쇄·다른 그림책·쪽 관리)는 하나의 단추 뒤에 접어 둔다.
2. 상단은 한두 줄로 줄인다. 위치를 알려 주는 것(‹ 서재, 제목)과 지금 할 일(쓰기·읽기, 보관함)만 둔다. 제목은 보이는 자리에서 바로 고친다.
3. 한 번 읽으면 되는 설명은 매번 위에 두지 않고, 그 설명이 필요한 접힌 자리로 옮긴다.
4. 글씨는 기기 거리에 맞춘다. 폰은 가장 작은 단계(캡션·작은 글)를 키우고, 터치 태블릿은 본문까지 한 단계 키운다. 데스크톱은 그대로 둔다.
