# 장 표시 정보의 분석과 검토

단일 실행 계획의 다음 미완료 항목을 조사했다. 지난기록 표시 경계 수정과 장 기본 설정 연결은 기존 2026-10-20 실제 엔진·파일 근거가 있어 반복하지 않았다.

현재 장 기본 설정은 제목·개요·기본 이미지·선택적 인물/음향을 제공하지만, 이전 ChapterWriter의 장 번호·갈래 표시는 현재 화면에서 접근할 수 없었다. 기존 `chapterNumber`/`branchLabel`과 `updateStoryChapter`를 사용해 접힌 상세를 추가한다. 표시 이름만 바뀌며 장의 order, 컷 배열, ID, Flow와 StageComposition은 바꾸지 않는다. 별도의 도메인/파일 형식 필드를 만들지 않는다.

수동 검토에서 제목에 번호가 들어 있고 chapterNumber가 없는 원고의 표시 불일치를 발견했다. 예: title='3장 · 이전 제목', order=1. 번호 입력은 실제 보이는3을 존중해야 하며, 갈래만A로 바꾸어도 표시가3장A로 바뀌어야 한다. 기존 원고를 일괄 변환하는 대신 명시적인 갈래 수정에서만 보이는 번호를 함께 기록한다. 이 경우 제목과 컷/장 순서는 그대로다.

숫자 입력은 입력 중 초안을 별도로 보존하고 포커스를 옮길 때 적용한다. 빈 값·0·음수·소수·지수 표기는 원고 값을 바꾸지 않는다. 한글 조합 중 갈래/제목은 입력할 수 있고 숫자/화면 전환은 차단한다. 숫자 초안 key는 작품·장·적용 번호를 포함해 다른 작품의 동일 ID와 섞이지 않게 한다.

첫 브라우저 실행은 로컬 서버 미실행으로 실패했고 해당 로그를 남겼다. 서버를 시작한 뒤 기존 정적 후보에서 상세 입구가 없음을 재현했다. 첫 구현 검사는 기본 장 설정 통과 후 내보내기 동작이 닫은 장 상세를 다시 열지 않고 입력하려 해 대기했다. 현재 UI의 실제 메뉴 열기 경로를 따라 다시 열도록 검사만 수정하고 실패 로그를 보존했다.

다음 항목은 장 자료 목록의 추가·제외 접근이다. 목록 제외가 현재 컷의 실제 배경/인물 또는 장 기본값을 지우지 않는다는 기존 의미를 먼저 대조한 뒤 구현한다. 장 표시 기능을 끝낸 것으로 장문·실기기·온라인 휴지통 결합까지 완료한 것으로 취급하지 않는다.

추가 검토: 제목3장B·order1인 원고의 번호만4로 고칠 때B가 사라지는 경로도 보완했다. 첫 표시 편집에서 현재 보이는 갈래를 보존하고, 명시 번호가 생긴 후 빈 갈래는 제목 속B로 되돌리지 않는다. 입력 key에 작품ID도 포함하며 이 경로의 보존 검사를 추가했다.
