# 현재 편집 버튼의 표시와 접근성 이름 대조

2026-10-26. 변경 없이 현재 정적 후보를 다시 관찰했다. 실제 기본편집의 `controls.json`, 원본 검사 `basic.json`, 최소 재현 `probe.mjs`/`probe.log`를 보존한다.

- 서재 버튼의 화면 글은 ‘서재’, 계산 이름은 ‘홈 · 서재로 이동’이다. 보이는 목적지가 이름에 포함된다. axe4.14의 최소 재현에서도 ‘서재로 이동’은 경고하고 정확히 ‘서재’는 경고하지 않았다. 설치된 검사기의 `isLabelContainedInName`은 문자열 포함이 아니라 `Intl.Segmenter`의 연속 토큰 일치를 사용한다. 이를 실제 읽기 실패나 전체 접근성 통과로 해석하지 않는다.
- 배경 선택 버튼은 ‘산속 계곡’과 ‘썸네일로 이미지 찾기’를 표시한다. 이름에는 컷·찾기 동작·선택 이미지가 들어가며 두 번째 줄은 `aria-describedby`로 연결된다. 실제 이름/설명 연결은 앞선 직접 검사 근거를 유지한다. 보이는 모든 문자열을 이름으로 합치는 검사 기준과 별도로 검토해야 하며, 이번 관찰로 경고를 삭제하거나 허용 목록에 넣지 않았다.
- `aria-hidden`을 안내에 추가하는 최소 실험도 경고를 없애지 않았다. 이를 제품 소스에 반영하지 않았다. 검사 통과만을 위한 불필요한 이름 변경은 하지 않았다.
- 실제 화면의 버튼 목적과 정보 구조를 소스·계산 이름·화면 글로 대조한 범위다. 실제 스크린리더/음성 조작 및 다른 화면의 전체 적합성은 미검증이다.
