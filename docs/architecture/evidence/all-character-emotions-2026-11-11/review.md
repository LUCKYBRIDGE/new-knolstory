# 모든 등장인물의 최소5종과 희노애락

2026-11-11 최신 사용자 결정: “각 등장인물들 이미지가 있다면 적어도 희노애락”, “각 인물별로 이미지5개 이상”. 이전 조연32종 목표에 수량만 더하는 방식으로 끝내지 않고, 개별 정체성마다 **기본·희(기쁨)·노(분노)·애(슬픔)·락(즐거움)**의 서로 다른5개 카드를 보장한다. [선정·누락·재사용·완료기준](plan.json), [현재 검증·실패/보완](checkpoint.json), [생성·원본/실행파일과 변환](generation.json), [체형 검토](normalization-review.json)가 근거다.

## 대상과 완료 기준

등록52항목 중 개별 정체성47개를 대상으로 한다. “선녀의 두 아이·흥부네 아이들·놀부네 아이들·용궁 신하들·도깨비들”은 군집용 별칭5개다. 군집 그림 하나를 여러 인물의 감정 수량으로 중복 계산하지 않는다. 아이들은 각자, 신하들은 물고기/게 신하, 도깨비는 개별 도깨비의 감정 구성을 제공한다. 날개옷·두레박 등 소품은 대상이 아니다. 짚 인형은 기존의 얼굴 없는 디자인을 유지하고 몸짓으로 감정을 구분한다.

47개 정체성마다5개 ID와5개의 서로 다른 이미지 해시, 동일한 개별 인물 연결과 편집 선택 가능 여부를 확인한다. 총235개의 지정 감정 카드다. 다섯 동작/복장만 있고 감정이 빠진 경우는 통과시키지 않는다. 희는 편안한 기쁜 미소, 락은 눈·입·몸짓이 더 활발한 웃음/즐거움으로 구별한다. 노를 걱정으로, 애를 피곤함이나 결심으로 대신 세지 않는다.

이전 자료와 조연 추가본에서 읽히는 감정25칸을 재사용한다. 부족한 감정과 개별 그림이 없던 선녀의 두 아이 기본 모습을 포함해165종을 생성한다. 최초 계획163종의 비교판 검토에서 일꾼의 억울한 품삯 요구와 선녀의 조용한 결심을 각각 분노/슬픔으로 재사용하기 어렵다고 판단해 별도2종을 추가했다. 동작 자료32종과 함께 이번 후속에서는197종을 추가하며, 그보다 앞서 추가한16종도 유지한다.

## 편집 연결과 보존

현재 지정 카드의 단일 소유자는 `packages/asset-registry/src/character-emotions.json`이다. 생성 계획은 제작·검토 근거이고, 실제 검색·감정 필터는 이 등록표와 현재 카탈로그를 사용한다. 기존 카드에 새 감정 역할을 연결할 때 원래 카탈로그 행·ID·revision을 덮어쓰지 않는다. 감정·상태 facet과 이름+기본/기쁨/분노/슬픔/즐거움 및 희·노·애·락 검색으로 찾을 수 있다.

앞선481개 카탈로그 행·순서·값과 기존 작품/원본/개인 저장소는 보존한다. 기존 작품 컷에 새 이미지를 자동 적용하지 않는다. 개별 이미지가 없었던 선녀의 첫째·둘째는 각각 새 기본 카드로 선택 목록의 대표 이미지를 연결하며, 이미 작성된 asset ID를 바꾸는 migration은 하지 않는다. Ren’Py에는 정확히 검토된 새 경로만 허용하고 임의 폴더·URL을 열지 않는다.

원본PNG는 `assets/source/characters/emotions-v3/`, 실행WebP는 `apps/web/public/assets/characters/emotions-v3/`에 별도 보관한다. 같은 비율의800×1200캔버스 변환과 참조 바닥을 사용한다. 비교판에서 선녀의 두 아이는 감정별 머리/몸통 크기를 개별 기본 그림 및 원래 두 아이와 대조해 균일 비율을 보완했고, 재시도 도깨비 기쁨의 지나치게 작은 체형도 보완했다. 앉기·숙임을 서 있는 실루엣 높이로 늘리지 않는다. 자세별 신체·종별 발/날개/집게·소품·알파 빈틈과 감정 차이는 색 배경의 인물별5칸 비교판에서 확인한다.

## 다른 컴퓨터와 실행 검사

```sh
pnpm install --frozen-lockfile
python3 -m pip install Pillow==11.3.0 fonttools==4.60.2
python3 scripts/prepare-expression-assets.py
# 실행WebP가 없을 때만 Git의 원본PNG에서 복원한다. 기존 수정 파일은 덮어쓰지 않는다.
python3 scripts/prepare-expression-assets.py --restore
pnpm runtime:build
pnpm build
pnpm exec playwright test --config tests/all-character-emotions.playwright.config.ts
```

공통 준비 명령은 이전16종·조연32종·감정165종을 모두 검사한다. 원본/실행 해시·geometry·클리핑을 대조한다. [기존 SDK·비공개 미디어 준비](../../reproducible-test-environment.md)는 별도다.

235카드 모두의 실제 Ren’Py 준비 경로와 실행 원본 해시를 가로/세로에서 확인하고, 전체 작품 파일 내보내기·새로고침과 원고 동일성을 비교한다. 편집기에서는47개 인물을 각각 검색해5칸을 확인하고 미리보기/취소/분노 적용/저장을 검사한다. 검사 코드만 추가한 상태와 실제 통과는 체크포인트에서 구분한다. viewport 모의는 실물 기기 검사가 아니다.

이 기록은 저장소·로컬 편집/재생 범위다. 운영API가 새ID를 허용하려면 다음 승인된 배포 때 동일646행 카탈로그를 포함해야 한다. 인증 업로드·공개 사이트 배포·새 실행 묶음의 권리/배포 검토 완료를 주장하지 않는다. 새 생성 파일은 기존 놀스토리 서비스/편집 사용 범위를 유지하며 CC0·무제한 제3자 자료실 허가로 바꾸지 않는다.
