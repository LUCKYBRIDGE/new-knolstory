# 선녀와 나무꾼 선택·합류 서사 재검토

2026-11-01. 사용자 요청: 장 번호보다 줄거리의 인과와 선택 결과를 먼저 확인하고, 겹치는 줄거리의 합류와 직전 교정의 타당성을 재검토한다.

## 기준과 검토 범위

- 기준 원고는 `representativeStories`의 `seonnyeo`를 실제 `resolveProvidedCatalogStory`에 통과시킨 현행 결과다. raw fixture에 교정 목록을 무조건 대입한 결과를 최종 판단 기준으로 삼지 않았다.
- Vite의 `ssrLoadModule('/packages/compatibility/src/index.ts')`로 실제 resolver를 실행하고, 아래 시간 표현과 경로 수치를 직접 확인했다. 주 작업자의 `.cache/branch-review-seonnyeo.json` 결과와도 대조했다. 이 캐시는 Git 인수인계의 필수 파일이 아니다.
- 166개 장·1,613컷·25개 선택 컷의 전체 연결을 열거했다. 시작부터 끝까지 64경로, 경로당 324~412컷, 네 엔딩 각각 16경로다. 진입 연결이 둘 이상인 합류 컷은 22개다.
- 본문은 공통 장면 전체와 텍스트가 달라지는 복제 장면을 읽고, 첫 만남·옷 찾기·가족 그리움·옷 반환 시점의 선택 기억, 옷의 위치, 시간, 하늘길 조건, 합류 직전 행동을 대조했다. 경로 수치만으로 서사 정상 판정을 내리지 않았다.
- 64경로를 실제 Ren’Py로 각각 처음부터 끝까지 재생한 검사는 아니다. 화면·음향·연출·독자 저장 복원 전체 검증과 구분한다.

## 재현할 경로

모든 경로는 `P1-v166-1`에서 시작한다. 첫 세 선택 `C1`, `C2`, `C3`의 A/B를 각각 조합한 여덟 진입 경로에 아래 여덟 경로가 붙어 총 64경로가 된다. `-v숫자`는 선택 기억을 보존하는 별도 원고를 가리키며 아래 표는 장면 계열 이름으로 줄였다.

| 이후 선택 | 결과와 합류 확인 |
|---|---|
| `C4:A → C5R:A` | 발견 당일 반환 → 선녀의 귀향 → `E1-4-v1-3` |
| `C4:A → C5R:B` | 발견 당일 반환 → 지상에 남음 → `E2-4-v5-7` |
| `C4:B → C4H:A → C5R:A` | 하루 숨긴 뒤 자진 고백 → 귀향 → `E1-4-v1-3` |
| `C4:B → C4H:A → C5R:B` | 하루 숨긴 뒤 자진 고백 → 지상에 남음 → `E2-4-v5-7` |
| `C4:B → C4H:B → C5H:A → C6C:A` | 계속 숨기다 질문받고 고백 → 약속을 요구하지 않음 → `E3-5-v23-7` |
| `C4:B → C4H:B → C5H:A → C6C:B` | 계속 숨기다 질문받고 고백 → 귀환 약속을 요구했다가 거둠 → `E3-5-v23-7` |
| `C4:B → C4H:B → C5H:B → C6L:A` | 거짓말 → 선녀가 옷 발견 → 앞을 막았다가 비킴 → `E4-9-v31-9` |
| `C4:B → C4H:B → C5H:B → C6L:B` | 거짓말 → 선녀가 옷 발견 → 처음부터 비킴 → `E4-9-v31-9` |

연결 재계산은 실제 resolver 결과의 첫 컷에서 `flow.type === 'choice'`의 모든 `options[].targetLineId`와 `goto.targetLineId`를 따라간다. 이 원고의 본문 컷들은 명시적으로 연결되어 있다. 종점별 경로 수는 위 표의 네 종점이 각각 16이다.

## 확정 수정 필요: 발견일과 고백일의 차이

현재 resolver에도 다음 네 컷이 그대로 남아 있다.

| 컷 | 현재 문장 | 권고 교정 |
|---|---|---|
| `E3-1-v30-7` | “사흘 전에 찾았소.” | “이틀 전에 찾았소.” |
| `E3-1-v30-8` | “사흘?” | “이틀?” |
| `E3-1-v108-7` | “사흘 전에 찾았소.” | “이틀 전에 찾았소.” |
| `E3-1-v108-8` | “사흘?” | “이틀?” |

근거는 `C4:B → C4H:B → C5H:A` 경로의 날짜다. `H1/H2`는 발견 당일 저녁, `H3-v48-1`은 “이튿날 아침”, 이어지는 `HB1`은 둘째 날이다. `HB2`는 셋째 날이며 `HB3-v44-1`은 “그날 밤”이다. 그날 고백하므로 옷 발견은 이틀 전이다. `v108`은 첫 만남의 기억만 다른 동일 고백 시점이며 날짜도 함께 고쳐야 한다. 뒤따르는 선녀의 되물음까지 맞춰야 대화가 어긋나지 않는다.

이 문제는 raw 원고부터 있던 표현이며 직전 장 번호 변경이나 마지막 저녁 문장 교정이 만든 오류가 아니다. 이 보고서는 발견과 권고를 기록한다. 구현·회귀·배포 여부는 [체크포인트](checkpoint.json)가 소유한다.

## 선택 기억과 겹치는 줄거리의 합류 판정

| 대상 | 본문과 연결을 대조한 판정 |
|---|---|
| 첫 만남 `C1:A/B` | `E3-1-v30` / `v108`, `E4-4-v39` / `v109`가 올바른 과거를 기억한다. A는 가까이 오지 말라는 요청을 받고 멈춘 행동, B는 위험을 설명하고 끝까지 싫다면 물러나겠다고 한 행동을 기억한다. 다른 선택의 경험이 섞인 사례는 확인하지 못했다. |
| 계속 함께 찾기 `C2:A/B` | `14-20`의 회상이 동행을 계속한 경로와 혼자 찾겠다는 뜻을 따른 경로에 맞는다. 이 뒤 공통 옷 발견·반환 선택으로 합쳐져도 옷의 소유·위치·발견 시점은 같아 충돌하지 않는다. |
| 가족 그리움 `C3:A/B` | `E2-3-v6-5`는 가족과 별을 보자는 기억을, `E2-3-v54-5`는 고향을 그리워해도 덜 좋아하는 것은 아니라는 기억을 사용한다. 각각 실제로 그 이야기를 들은 경로로 연결된다. |
| 당일 반환 / 하루 뒤 자진 고백 | `E1-3-v14`에만 숨긴 일의 반성이 있고, `E2-2-v17/v62`에만 남겠다는 결정으로 상처를 덮지 말라는 대화가 있다. 직접 돌려준 경로에 숨긴 일을 회상시키지 않는다. 공통 후일담으로 합류하기 전에 차이를 표현한다. |
| 늦은 고백 `C6C:A/B → E3-4-v24` | B는 귀환 약속을 요구하지만 `C6C-B-v26-6`에서 “약속하지 마시오.”로 요구를 거둔다. 그 뒤 공통 작별 장면으로 합류하므로 지키기로 한 약속이 갑자기 사라지는 오류는 아니다. |
| 떠남 `C6L:A/B → E4-8-v32` | A에서도 `C6L-A-v33-7`에서 옆으로 비키고 다음 컷에서 사과한다. 두 경로 모두 길이 열린 상태로 공통 퇴장에 합류한다. 막고 있는데 곧바로 빠져나가는 연결은 아니다. |
| 거짓말 엔딩의 목적지 | 하늘길을 놓쳤다는 설명 뒤 `E4-8-v32-7`은 마을로 내려가는 길을 걷는다. 집을 떠나는 것이며 갑자기 하늘로 귀향하는 내용이 아니다. |
| 늦은 고백 엔딩의 재방문 | `E3-5-v23-1~2`는 하늘에서 날개옷을 고치고 몇 계절이 흐른 후 방문 시기가 다시 왔다고 설명한다. 같은 옷으로 이미 닫힌 길을 즉시 건너오는 모순은 아니다. |

반복 저장된 장면이 같은 독서 경로에서 두 번 이어져 옷을 다시 발견하거나 같은 고백을 반복하는 연결은 확인하지 못했다. 반응 장면의 차이가 작다는 이유만으로 별도 엔딩을 만들거나 기존 합류를 나눌 근거도 발견하지 못했다.

## 직전 변경과 번호에 대한 재평가

- `connectCatalogChapterIdentity`는 장 표시 번호·갈래·제목과 표시 목록을 바꾸며 컷 본문·Flow·선택 대상·런타임 `order`는 바꾸지 않는다. 줄거리를 번호에 맞춰 옮긴 변경은 아니다. 이 사실은 이야기 내용이 모두 옳다는 증명과는 구분한다.
- 직전 `E4-7-v36-1` 교정 “그날 저녁, 어젯밤보다 조금 더 이지러진 달이 뜬다.”는 타당하다. 바로 앞 `E4-6-v37-5`의 “오늘 밤까지 혼자 생각하게 해줘요.”와 같은 장 `E4-7-v36-6`의 “하루 종일요.”가 그날 아침부터 저녁까지의 숙고를 가리킨다. 발견 다음 날 아침과 그날 저녁의 순서가 명료해진다.
- 첫눈 뒤 `8-v81-1` 계열의 “가을이 깊어졌다.”는 시간감이 다소 느슨하지만 앞 장이 “늦가을, 이른 첫눈”이라고 명시한다. 겨울 뒤 가을로 되돌아간 확정 모순으로 분류하지 않았고 변경을 권고하지 않는다.
- `C5R`는 나무꾼의 응답에 따라 선녀가 자신의 귀향/정착 이유를 밝히는 설계다. 선택이 다른 인물의 결정을 즉시 정하는 듯한 인상은 별도 서사 개선 주제가 될 수 있지만, 이번 검토만으로 잘못된 경로나 사건 혼합으로 단정해 Flow를 바꿀 근거는 없다.

## 한계와 보존

이번은 실제 resolver 본문과 경로의 편집 검토이며 모든 문장의 문체 전수 교정, 모든 플레이의 시각·음향 검증, 실기기 검증 또는 작품 전체 무결점 판정은 아니다. 발견한 네 날짜 문장 외에 선녀 원고의 Flow나 선택·엔딩을 다시 배치해야 할 확정 결함은 찾지 못했다. 개인 수정본, 원본 fixture, 기존 증거는 이 보고서 작성으로 바꾸지 않았다.
