# 옹고집·흥부 놀스토리 분기와 합류 서사 검토

2026-11-01. 장 번호의 단조 증가를 서사 품질의 근거로 삼지 않고, 선택 이후의 사건·기억·시간·인물 반응과 합류를 검토했다. 제품 원고를 수정하지 않은 검토 기록이다. 후속 수정과 검증의 소유 기록은 같은 폴더의 `checkpoint.json`이다.

## 실제 읽은 원고와 검토 오류의 정정

`representativeStories`의 두 원고를 `resolveProvidedCatalogStory`로 변환한 실제 결과를 Vitest에서 추출했다. 독립적으로 만든 두 추출 결과의 전체 프로젝트 값도 동일했다. 임시 추출 파일은 `.cache/branch-ong-review/*-current.json`과 `.cache/branch-review-*.json`에 있다. 캐시는 Git 인계 자료가 아니므로 검토 대상은 위 코드 경로로 재생성한다.

첫 검토의 Python 도구는 교정 목록의 `before` 일치를 확인하지 않고 `after`를 대입했다. 이 방법은 올바른 현행 원고 추출법이 아니다. 이를 발견한 뒤 실제 resolver 결과와 모든 컷을 다시 대조했다. 흥부 본문 차이는 0개이고, 옹고집 차이는 직전 배포에서 교정한 자동 해설 3개뿐이었다. 그 3개는 실제 resolver의 현재 본문으로 재확인했다. 따라서 아래 흥부 `scene-7-13`의 지적은 오탐이 아니지만, 최초 추출 방식 자체는 정정한다.

특히 fixture의 `scene-7-13`에는 이미 “빌린 것이 있으면 갚았고”라는 조건형이 있다. 그러나 `reader-text-rabbit-heungbu.json`의 `before`가 그 전체 본문과 일치하므로, 실제 제공본에서는 “빌린 것은 갚았다”라는 단정형 `after`가 적용된다. fixture만 읽어서 현행 제공본을 판정하면 이 결함을 놓칠 수 있다.

## 경로와 읽기 범위

- 옹고집: 현재 시작점에서 도달하는 345컷, 선택 조합 16개의 완결 경로. 첫 모질음 2종 × 관아 선택 2종 × 귀가 후 아이 반응 2종 × 삯 선택 2종이다. 원고의 미연결 옛 108컷은 현행 경로로 간주하지 않았다.
- 흥부: 도달하는 277컷, 겨울 선택 2종 × 마지막 도움 방식 2종의 완결 경로 4개.
- 모든 도달 본문을 읽고 공유 구간은 재사용하면서, 선택별 사건과 다시 만나는 지점의 문맥을 대조했다. 경로 수와 컷 수는 ID 기반 열거로 확인했다.
- 실제 Ren’Py에서 20개 경로를 모두 조작해 재생했다는 뜻은 아니다. 점수·화면 출력·실기기 동작의 완료 증거로 확대하지 않는다.

## 옹고집: 선택의 기억과 합류

| 선택·합류 | 확인한 컷 또는 장 | 서사 판단 |
|---|---|---|
| 장작부터 패라고 함 / 먼저 쫓아냄 | `start:8` → 두 `part1-court-*` 장 | 노동을 명한 대사, 삯을 깎는 이유, 짚신을 거절한 말이 갈래별로 다르다. |
| 최초 모질음이 응보에서 되돌아옴 | 두 `fake-route-*` 장의 8~20번 부근 | 첫 선택의 대사가 자기에게 되돌아온다. 첫 갈래의 ‘젖은 장작’, 둘째 갈래의 ‘도끼질이 느림’이 뒤섞이지 않는다. |
| 오래 함께 산 남편과 돌아감 | `part1-court-*:39/40` → `real-route-*` → `real-loop-testimony-*` | 가족을 대하는 태도가 변하지 않아 다시 판정받는 추가 사건이 있다. 처음부터 또 다른 옹고집과 돌아간 경로와 구분된다. |
| 아이를 감싼 사람과 돌아감 | `fake-first-verdict-*` | 첫 판정에서 바로 쫓겨난다. 위 경로와 같은 떠돌이 구간에 들어가도 ‘첫/두 번째 판정’ 서술이 서로 침범하지 않는다. |
| 떠돌이 이후 가족 기억 초기화 | `fake-route-*`의 32~44번 부근 | 반 년/집의 일주일 차이와 관아 기억 소거를 명시한다. 귀가 뒤 아이의 경계는 관아 기억이 아니라 오래된 가정 내 두려움으로 읽을 수 있다. 초자연적 설정이며 시간 수치만 고칠 대상이 아니다. |
| 아이에게 친절 + 삯 정상 지급 | `b-meal-act` → `b-after-meal-days` → `b-vase-care` | 가족과 일꾼 양쪽에 달라진 태도를 보인 뒤 공통 회복 구간으로 간다. |
| 아이에게 친절 + 삯 삭감 | `b-vase-stick:0~3` | 삭감 발언 뒤 일꾼의 손을 보고 자기 말을 번복한다. 선택이 없던 일로 사라진 것이 아니라 짧은 자정 사건이다. |
| 아이를 꾸짖음 + 삯 정상 지급 | `b-child-scene` → `b-vase-care-after-harsh:1~5` | 아이에게 따로 사과하고 까치 이야기를 다시 듣는다. 친절 경로와 합류하기 전에 이전 잘못을 수습한다. |
| 아이를 꾸짖음 + 삯 삭감 | `b-fake-warning:5` | “아이의 말을 끊더니, 약속한 삯까지 저버리는군”으로 두 선택을 함께 반영하고 퇴출 결말이다. |

이 범위에서 확정된 잘못된 합류·사건 역행·이전 선택 기억 누락을 찾지 못했다. 첫 판정 이후 같은 떠돌이 길로 모이는 것과 마지막 회복 결말이 공유되는 것 자체는 오류가 아니다.

앞서 고친 세 `real-loop-testimony*:17`의 “부인은 아이를 감싸 준 옹고집을 바라보았다”는 다음 부인의 판정 대사와 연결된다. 자동 진행을 선택문처럼 썼던 표현을 제거했으며, 판정 사건이나 선택 결과를 바꾸지 않았다. 바꾼 8개 장 제목도 실제 아이 대화·삯 지급·사과 사건에 맞는다.

## 흥부: 공통 원고에 남은 갈래 편향

### 수정 권고: 상환 여부의 조건이 교정 과정에서 사라짐

`scene-4-23`에서 `choice-winter-other-way`를 고르면 `scene-5b-1`은 놀부의 곡식을 빌리지 않기로 했다고 명시한다. 이후 이웃과 품·물건을 주고받으며 겨울을 넘긴다. `scene-5b-17`에서 `scene-6-1`로 합류하고, `scene-7-13`에 이른다.

실제 제공본 `scene-7-13`의 “빌린 것은 갚았다”는 명시되지 않은 부채를 B 경로에도 확정하는 표현이다. fixture의 “빌린 것이 있으면 갚았고”가 두 갈래를 고려했던 조건을 문장 축약 과정에서 잃었다. 연결 변경 없이 조건을 복원하는 것이 우선이다.

최소안: 현행 “빌린 것은 갚았다”를 “빌린 것이 있으면 갚았다”로 바꾸어 조건만 복원한다. A 경로의 상환을 보존하고 B 경로에 새 부채를 단정하지 않는다. 이 한 문장을 위해 새 점수나 새 컷을 추가할 필요는 없다. “받은 도움을 잊지 않았다”만으로 바꾸면 A의 구체적인 상환 의미가 약해지므로 조건형 복원을 권고한다.

### 정서 편향 개선 권고: 형의 간섭 경험을 공통화함

`scene-11-12`는 “도움이 마냥 고맙지는 않았다”, “그 손이 자기 삶에 어디까지 닿아도 될지 고민”이라고 회상한다. 이는 `scene-5a-14~17`의 놀부 간섭과 경계 설정에 직접 대응한다. 반면 B는 이웃 도움을 배운 길이다. 사실상 불가능한 기억이라고 단정하지는 않지만, 공통 원고가 A의 정서를 강하게 전제한다.

최소 방향은 두 길 모두에 있는 가족 의논·도움의 필요·함께 결정하기를 회상하고, 현재 놀부 가족의 선택으로 연결하는 것이다. 예: “도움이 필요했지만, 가족이 앞으로 어떻게 살아갈지도 함께 생각해야 했다. 누군가의 손 덕에 겨울을 넘겼다. 형네를 돕는 일도 두 가족이 함께 방법을 정해야 했다.” 선택별 회상 기능을 새로 도입할 정도의 문제로 보지 않는다.

### 그 밖의 시간·사건·결말

- 5A는 초봄 밭일과 상환이 시작된 뒤, 5B는 겨울을 넘긴 뒤다. 공통 `scene-6-1`의 봄이 무르익을 무렵은 양쪽과 맞는다.
- 제비 치료 → 다음 해 박 → 놀부의 모방 → 그 다음 해 박 → 겨울 도움 제안의 연도·계절 순서가 맞는다.
- `scene-11-14`의 옛날 놀부 집 문 앞에 섰다는 회상은 두 갈래 공통인 `scene-4-13`에서 이미 일어난 일이다.
- `scene-12a-6`의 “또 곡식을 보낼 거냐”는 양쪽 경로 공통인 7장의 이웃 도움에 연결할 수 있다.
- 12A는 겨울 동거 후 따로 살림을 마련하고 공동 밭을 운영한다. 12B는 처음부터 별도 살림을 도우며 서로 품을 나눈다. 별도 경로의 사건을 서로 잘못 회상하거나 결말이 뒤섞이는 추가 확정 결함은 찾지 못했다.

## 장 번호 판단의 경계

이번 서사 검토로 앞선 번호 부여가 원고의 Flow를 바꾼 것은 아님을 재확인했다. 다만 DAG의 깊이는 표시 번호를 정하는 구현 수단이며, 사건상 같은 단계인지의 문학적 판단을 대신하지 않는다. 갈래의 추가 사건 수가 다르면 공통 장에 도착할 때 번호가 건너뛸 수 있다. 이 기록은 모든 번호가 최선의 편집적 구획이라는 확정이나 작품 전체 교정 완료를 뜻하지 않는다.
