# 로딩 문구의 원고·기능·출처 대조

2026-10-20 사용자 결정: 현재 작품의 내용, 실제 웹 기능, 독서 관련 명언을 짧게 보여준다. 문구 원본은 `apps/web/public/loading-stories.json`이다. 이 문서는 수동 대조 근거를 보존한다. 원고와 이전 검증은 변경하지 않았다.

## 작품 소개

원작과 놀스토리판의 여덟 fixture를 함께 읽고, 표시 문구는 사건·대사 자체도 공개하지 않는 주제/읽기 관점으로 한정했다. 판본별 사건 자체를 소개하지 않고 원고에서 확인한 주제로 한정해 원작의 전개나 다른 작품의 시점을 섞지 않는다. 이전 답변의 ‘나무꾼의 시점으로만 진행’도 새 문구의 사실로 자동 채택하지 않았다. 실제 도입에는 해설과 여러 인물의 대사가 있고, 도움을 결정하는 선택 문구가 있다.

| 작품 | 수동 확인한 원고 | 현재 소개의 범위 |
|---|---|---|
| 별주부전(토끼전) | `rabbit.json` 도입 ‘나는 용궁 대청에서 용왕님을 모시는 자라였다.’ 및 토끼에게 잔치 초대/도움 요청으로 말을 건네는 선택 | 부탁을 전하는 말의 차이. 주인공 시점·여정·만남·초대 등의 사건을 미리 설명하지 않음 |
| 흥부전 | `heungbu.json` ‘반쪽짜리 떡’에서 배고픈 아이들에게 떡을 나누는 흥부와 ‘너 먹을 건?’이라고 묻는 놀부 | 두 형제가 중요하게 여기는 ‘몫’이라는 주제. 떡을 나누는 사건/실제 대사는 표시하지 않음 |
| 선녀와 나무꾼 | `seonnyeo.json` 계곡/폭풍/빗속의 하늘길/나무꾼의 등장 뒤 ‘어떻게 도울까?’ 선택. 물·겉옷 제공/집에서 비 피하기라는 실제 문구 | 도움을 주려는 마음과 상대가 원하는 도움이라는 주제. 폭풍/만남/도움 선택의 구체적인 사건을 표시하지 않음 |
| 옹고집전 | `onggojib.json` 도입 ‘옹고집의 시점’, 밥상에서 아이/부인에게 건네는 말, 이후 가족 대화와 반응을 고르는 선택 | 가까운 사람에게 건네는 말의 무게. 집안 사건·판결·정체·결말을 표시하지 않음 |

## 실제 기능 안내

| 안내 | 소스·행동 대조 |
|---|---|
| 기기의 작품 파일 저장 / 온라인 업로드 | `local-work-file.ts`, `local-work-file-actions.tsx`, 저장 계약의 로컬 파일 우선. 브라우저 임시 보관을 파일 저장 완료로 부르지 않음 |
| 파일 가져와 이어서 편집 | `WorkspaceManagement`와 `confirmAuthoringImport`의 명시 가져오기·내 사본 흐름. 원래 파일에 자동 덮어쓴다는 표현 없음 |
| 배경·글로 컷 작성 | 기본편집의 배경 선택과 글상자 textarea |
| 설정에서 글 편집 | `story-editing-workbench`와 편집 설정의 화면 선택. 한 장의 여러 컷 글을 모아 편집 |
| 선택지 편집의 문구·다음 컷 | 실제 개방 도구와 `StoryChoiceWritingDialog`. 미개방 상태에서 상시 수정 가능하다고 쓰지 않음 |
| 음향·연출·선택지 개별 사용 | `editor-preferences` 및 편집 설정의 명시 개방 |
| 지난기록 | `reader-chapter-history`와 실제 읽은 현재 장의 대본. 미열람 본문이나 임의 컷 이동을 안내하지 않음 |
| 빠른 저장 | `StoryPlayerMenu`의 독자 진행 저장. 작품 파일 저장과 다르다고 명시 |

## 독서 명언의 원문 확인

기존 번역서의 한국어를 복사하지 않고 원문의 뜻을 짧게 직접 옮겼다. 화면에는 저자·저작과 문장만 표시하고, 출처 URL·절·옮김 설명은 정식 JSON에 보존한다. 같은 두 문장을 두 작품씩에 배정해 작품별 선택 확률을 유지한다.

- 프랜시스 베이컨, 『수상록』의 「Of Studies」: 독서·대화·글쓰기의 효용을 말하는 첫 문장을 사용했다. [Project Gutenberg 원문](https://www.gutenberg.org/files/575/575-h/575-h.htm). 한국어: ‘독서는 사람을 풍부하게 하고, 대화는 민첩하게 하며, 글쓰기는 정확하게 한다.’
- 르네 데카르트, 『방법서설』 제1부: 훌륭한 책을 읽는 일을 과거 저자들과의 대화에 비유하는 구절을 짧게 옮겼다. [Project Gutenberg 원문](https://www.gutenberg.org/files/59/59-h/59-h.htm). 한국어: ‘좋은 책을 읽는 것은 그 책을 쓴 옛사람들과 대화하는 것과 같다.’

## 표시와 확률

총16항목: 각 작품에 기능 안내2개·작품 소개1개·명언1개씩4항목이다. 작품은 각25%, 기능 안내50%·작품 소개25%·명언25%다. 한 번에 라벨과 한 문단 하나만 표시한다.4초마다 같은 작품의 다른 항목을 무작위로 골라 교체하고 바로 같은 문구를 반복하지 않는다. 캐릭터는 로딩당 한 번 고른 뒤 유지하고, 다른 캐릭터 이미지 요청이나 안내를 읽기 위한 준비 지연을 추가하지 않는다. Web unmount/native presplash 제거·pagehide 때 타이머를 정리한다. 실제 준비 완료·입력·원고 보존은 기존 동작을 따른다.
