# 선녀와 나무꾼: 원작 읽기·놀스토리 문장 교정

## 범위

- 원작 읽기 `classic-seonnyeo-tale`: 83컷의 흐름을 확인하고 24컷 교정. 이 판은 여러 전승의 대표 서사를 현대어로 재구성한 제공본이며, 고문헌 원문을 직접 교감한 작업은 아니다.
- 놀스토리 `pinky-review-main-004`: 1,613컷 중 도입·전환·결말의 문장 12종을 선별해 분기별 동일 문구 42컷에 적용. 전체 분기의 문학적 완성도를 검토했다는 뜻은 아니다.
- 이번 교정은 `reader-edit-seonnyeo.json`의 원문 일치 조건을 가진 제공 카탈로그 교정 자료이다. 기존 `reader-text-seonnyeo-onggojib.json`의 선녀 교정 ID와 겹치지 않는다.
- 원본 fixture를 수정하지 않았다. 컷 ID, 순서, 화자, 선택지, Flow, 점수, StageComposition, 배경·인물·음원·효과 필드를 변경하지 않았다.

## 교정 원칙과 보존한 사실

원작 읽기는 전래 이야기의 서술 어조를 유지하며 긴 연결문과 반복 수식을 덜었다. 사슴을 숨겨 준 일, 날개옷을 감춘 주체, 아이 셋 이전의 금기와 실제 두 아이, 두레박을 통한 재회, 어머니를 향한 그리움, 용마에서 내리지 말라는 두 번째 금기, 뜨거운 호박죽과 낙마, 재회 실패와 수탉 유래형 결말을 보존했다. 이야기의 문제적 행동을 새로운 교훈으로 정당화하거나 결과를 바꾸지 않았다.

놀스토리는 전승과 다른 설정을 보존했다. 폭풍에 날아간 날개옷, 소나무 뿌리와 흙에 묻혔다가 다시 드러난 원인, 마지막 보름밤의 기한, 천의 손상과 달빛 속 은빛, 선녀가 스스로 머무르거나 떠나는 각 선택을 바꾸지 않았다. 짧은 대사에는 불필요한 손질을 하지 않고, 행동·발견·시간 경과가 겹친 문장을 나눴다. 동일 문장으로 표현된 분기 변형은 함께 정리했다.

가로 3줄·세로 5줄을 맞추기 위한 임의 문자 수 절단은 하지 않았다. 실제 표시 페이지는 기본 글꼴 측정과 문장 경계를 따르며 독자가 글씨를 키운다고 원고나 페이지 분량을 다시 바꾸지 않는다.

## 검증

교정 자료 66개 항목의 `before`가 fixture의 해당 ID 원문과 정확히 일치함을 확인했다. 교정 자료 내부 `(projectId, lineId)` 중복 및 기존 1차 교정 자료와의 ID 충돌은 0건이다. `after`는 비어 있지 않고 원문과 다르다. 원본 fixture 변경은 없다. 실제 카탈로그 적용·런타임 검증은 루트 작업에서 통합한다.
