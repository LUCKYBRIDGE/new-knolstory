# 흥부전 원작 읽기·놀스토리 문장 교정 검토

사용자가 원작 읽기와 놀스토리 모두의 문장·구성 교정을 요청한 범위의 추가 교정이다. 원작 읽기는 여러 이본을 현대어로 재구성한 제공본의 서술을 다듬는 작업이며, 특정 고전 원문의 교감·번역본을 새로 확정한 것은 아니다.

## 적용 범위

- `classic-heungbu-tale`: 125컷 중 21컷. 도입 3, 생계 4, 제비·결실 2, 복·소문 3, 놀부 모방 2, 손실 4, 화해·맺음 3컷.
- `heungbu-nolbu-nolstory`: 277컷 중 추가 13컷. 기존 첫 교정과 ID 중복 없음. 도입·분가·생계, 두 생계 선택 분기, 박 사건, 화해의 두 결말을 포함한다.
- 소유 파일은 `packages/compatibility/src/reader-edit-heungbu.json`. 원본 fixture는 수정하지 않았다. 각 교정은 projectId, lineId, 원문 일치 조건으로 적용할 수 있다.
- 문장·절·문단 호흡만 교정했다. 컷 ID·순서·화자·분기·점수·연출·음원은 변경하지 않는다. 기본 3줄·5줄에 억지로 맞추려고 사건을 삭제하거나 임의 글자 수로 자르지 않았다.

## 보존한 핵심

원작 읽기의 재산 독점, 품팔이와 대신 벌을 받으려다 늦은 일, 제비의 치료와 계절 변화, 세 박의 복, 놀부의 의도적 가해, 재산 손실, 흥부의 도움과 놀부의 뉘우침을 유지했다. 마지막 해설의 기존 교훈은 문장 호흡만 나누고 새로운 도덕 평가를 추가하지 않았다.

놀스토리는 분가 때 흥부가 빈손으로 쫓겨나지 않는 설정을 건드리지 않았다. 곡식을 빌리는 분기에서는 약속대로 일하는 흥부와 놀부의 농사 역량을, 빌리지 않는 분기에서는 노동 때문에 잃는 가족 시간을 보존했다. 놀부의 통제 문제와 지원의 실제 효용 중 어느 한쪽만 지우지 않았다. 공동생활 결말의 갈등 조절과 별거 결말의 자립 지원·상호 도움·경계도 유지했다. `scene-8-7`은 흥부를 철없는 동생으로 보는 판단이 놀부의 생각임을 명시한다.

## 검증

JSON 34행의 before를 fixture의 동일 projectId/lineId와 대조했고, 기존 `reader-text-rabbit-heungbu.json`과 교정 ID가 겹치지 않음을 확인했다. after가 before와 같은 행은 없다. 이는 텍스트 데이터 검증이며 실제 런타임 통합과 화면 검증은 상위 통합 작업의 범위다.
