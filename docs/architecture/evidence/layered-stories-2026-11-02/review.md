# 배경·인물 분리 구현 검토

2026-11-02. 현행 코드·제공 원고와 실제 이미지 연결을 읽어 검토한 기록이다. 적용 범위는 원작·놀스토리 8판본의 컷이며, 그림책의 쪽 삽화와 표지는 별도 용도다. 최종 검사 수치·커밋·배포 판정은 [단일 실행 계획의 재개 지점](../../product-completion-plan.md#재개-지점)에서 현재 근거를 확인한다. 이 문서는 배포 완료를 선언하지 않는다.

## 연결과 보존

[컷 조사](audit.json)에서 인물이 포함된 배경을 사용하던 37컷을 식별했다. 교체는 [공식 원고 시각 교정](../../../../packages/compatibility/src/catalog-layered-scenes.ts)을 통해 인물 없는 배경과 개별 인물로 연결한다. 주변 컷도 복장·신발·앉기·치료 상태가 이어지도록 교정한다. 본문·선택지·이동 경로·점수·음향·연출 데이터를 새 줄거리로 다시 쓰는 작업은 아니다.

[제공 작품 갱신](../../../../packages/compatibility/src/reader-text.ts)은 정확히 알려진 공식 판본만 갱신한다. 개인이 바꾼 제목·원고·배치 등의 차이가 있으면 전체 개인 작품을 보존한다. 기존 이미지의 원본·ID도 유지하며, 새로 만든 자료 11개는 별도 ID로 등록했다. 내역은 [생성·변환 근거](generation.json), 편집 선택 정책은 [등록·검색·비율 검토](picker-and-proportions.md)를 따른다.

## 검토에서 발견해 반영한 교정

| 확인한 문제 | 현행 처리 |
|---|---|
| 군집 그림을 개별 배우로 바꾸면서 우측 유령 연출이 부인·아이·하인에게도 적용될 수 있음 | 가짜 옹고집과 해당 컷의 동석자는 좌측 두 명으로 구성하고, 우측 진짜 옹고집의 기존 키·유령 이미지·연출을 보존한다. 품삯·부인·아이 장면은 세 명으로 제한한다. |
| “낡은 짚신으로 갈아 신었다” 뒤에도 눈이 들어오던 찢어진 짚신 그림이 이어짐 | 넝마옷은 유지하고, 교체한 짚신을 신은 별도 모습을 연결한다. 귀가 후에는 앉아 치료받는 모습, 보름 뒤에는 기존의 깨끗한 옷으로 넘어간다. |
| 관아에서 두 옹고집의 대비가 필요한데 진짜 옹고집이 빠짐 | 포졸이 물리는 컷에는 가짜·막내·진짜·포졸을, 부인을 올려다보는 컷에는 가짜·막내·부인·진짜를 배치한다. 전체 네 명 한도를 지킨다. |
| 표지·그림책에서 정상 선택 가능한 삽화에도 “이전 이미지” 안내가 표시됨 | 검색 결과·적용 가능 여부·현재 이미지 안내에 같은 `allowSceneIllustrations` 문맥을 전달한다. 표지의 기본 자료 선택도 같은 정책을 사용한다. |

배우가 있는 변경 컷의 연출도 대조했다. 유령 장면은 단순히 본문을 보존하는 것만으로 충분하지 않아 배우 정체성과 좌우 연출의 대상까지 확인했다. 그 외 검토한 교체 컷에서는 배우를 대상으로 한 효과 키가 추가로 유실되는 사례를 찾지 못했다. 현재 제공 원고는 각 장 안에서 배열 순서와 `order`가 일치해 복장 상태를 순서대로 연결할 수 있다.

## 실제 화면과 검증의 경계

초기 연결 상태에서 휴대폰 크기 390×844와 가로 1280×800의 Ren’Py 재생·작품 파일 내보내기·재열기를 두 실행으로 검사했다. 각 실행은 도끼질·발 치료·도깨비 소동·용궁 포위 네 장면을 포함했다. 이는 모든 컷의 사람 검토나 물리 휴대폰 검증을 뜻하지 않는다. 이후 추가한 신발 변형과 검토 교정까지 포함한 최종 재검사 결과는 상위 실행 기록에서 확인해야 한다.

세로 화면은 대사의 주화자, 해설의 지정된 행동 주체, 지정이 없으면 첫 배치 인물 한 명을 중심으로 보여 준다. 선택지에서는 인물을 숨기고, 명시적으로 비운 인물 배치는 그대로 빈 상태다. 가로 화면의 다인 배치와 작품 파일에 저장된 전체 배역은 유지한다. 이 해석은 Runtime Core가 소유하며 별도의 Web 이야기 렌더러를 추가하지 않는다.

## 복식 참고와 한계

[국립민속박물관 어린이박물관의 전통 복식 자료](https://www.nfm.go.kr/kids/user/content.do?pageId=PAGE_000000000000053)와 [전통문화포털 복식 자료](https://www.kculture.or.kr/clothes/code/943/menu/923/idx/176/currentPage/6)를 일반적인 복식 참고로 확인했다. 기존 인물의 도포·저고리·치마·갓 등 외형을 이어 가며 원고가 요구하는 헤짐·신발·치료 상태를 구분했다. 특정 이본의 정확한 시대·신분별 복식을 모두 고증했다는 주장은 하지 않는다. 물고기 신하·게 신하·도깨비는 전래 이야기의 의인화·환상 인물이라는 한계도 유지한다. 참고 사이트의 이미지를 새 자료로 복사하지 않았다.

새 이미지의 서비스 사용 허가와 SDK·음원 권리는 구분한다. 생성 사실을 기존 이미지 전체의 직접 제작 증명이나 CC0 선언으로 확대하지 않는다. 실행 패키지가 바뀌면 [이번 빌드의 정확한 출처 검토](runtime-review.json)를 갱신하며, 이전 빌드의 검토를 새 바이트에 자동 재사용하지 않는다.
