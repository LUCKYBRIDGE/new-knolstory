# 넉넉한 글 상자 후보

사용자는 모바일에서 글 상자를 더 크게 허용하고, 앞선 예의 두 배도 괜찮으며 한 컷을 억지로 두 화면으로 나누지 않기를 요청했다. 세로 약8줄/낮은가로 약5줄을 실제 글꼴 줄 높이로 계산해 담는 후보로 수정했다. 실제 컷·원고·인물 배치는 바꾸지 않는다.

- [비교 목업](comparison.png): 이전 작은 상자, 같은 원고 전체, 더 긴 글의 확장 예시.
- [검증 근거](checkpoint.json): 순수12개(고정시드1000포함), 글30종조합, 같은원고6구도/긴원고6구도.
- 운영에는 아직 배포하지 않았다. 이전 모바일 갤러리는 당시 후보의 기록이다.

초장문/선택지 추가 회귀 첫 실행은 같은cut/text의 읽던 위치를 유지해 선택지예시가 마지막페이지에서 시작했다. 검증예시의새읽기ID를 부여해 바로잡았으며 실제 읽던위치유지 기능은 약화하지 않았다.
