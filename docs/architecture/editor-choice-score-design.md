# 최종 도안 — 선택지와 이야기 점수 편집

2026-10-11. 사용자의 선택지/점수까지 포함한 최종 이미지 요청을 반영한다. [최종 구성](editor-redesign-final.md)의 글 중심 구조와 승인된 글 상자를 유지한다. [현행 점수 계약](score-narrative-contract.md)을 확인해 기존 지원과 새로운 UI 제안을 구분한다. 제품 코드·원고·저장 형식은 변경하지 않았다.

## 하나의 기본 구성, 세 편집 영역

1. 현재 컷의 선택지:문구·도착 컷/글 요약·점수 변화 요약·표시 조건 요약을 한 카드로 묶는다. 선택지 순서/삭제는 카드 메뉴, 추가/전체 흐름은 목록 하단이다. 상세는 선택한 카드 하나만 연다.
2. 작품의 이야기 점수:작품 메뉴에서 이름·뜻·시작 값과 사용 위치를 관리한다. 선택지에서도 접근하고, 돌아오면 같은 선택지 초안/스크롤/초점으로 복귀한다. 이름 변경은 ID 연결을 보존한다. 사용 중 삭제는 참조 위치를 안내하고 먼저 해제하도록 한다.
3. 점수에 따른 다음 이야기:Flow의 조건 경로를 위에서부터 판단하고 첫 만족 도착을 사용한다. 기본 도착을 같이 보여준다. 독자가 고르는 choice와 자동판단 goto를 한 모델처럼 합치지 않는다.

## 열었을 때 보이는 실제 설정

- 선택 결과:`점수 항목 → 더하기/이 값으로 바꾸기 → 값`, 문장으로 결과, 여러 변화 추가/삭제/순서. 음수 더하기는 빼기다. 점수는 선택 직후 바뀐다.
- 표시 조건:`모두/하나라도 만족 → 점수·비교·값`, 조건 추가/제거와 설명. 조건은 선택하기 전 현재값으로 검사하고 자신의 증가값으로 자신을 표시하지 않는다.
- 조건 경로:조건/도착 글 요약/위·아래 순서/기본 도착/전체 흐름 접근. 미연결·작품 끝·컷 지정은 다르다.
- 점수를 사용하지 않으면 문구와 도착만 편집한다. 예시 신뢰/용기 점수나 설정을 자동 주입하지 않는다.
- 값은 정수이며 현행 ±1,000,000 검증과 개수 제한을 유지한다. 잘못된 임시 입력으로 원고/저장을 바꾸지 않는다. 이름·뜻·원고를 자동 번역하지 않는다.

## 결과 확인과 경계 상태

결과 확인 도안은 예시 경로의 신뢰2/용기1, 첫 선택 후 신뢰4, 용기3 조건의 숨김 이유와 도착을 함께 보여준다. 이 설명은 작가용이며 실제 독자에게 숨겨진 선택지를 회색 버튼으로 보여준다는 계약이 아니다.

실제 현재 점수는 Core가 선택ID와 읽기 경로로 계산한다. 중간 컷부터 시작하면 시작값을 사용하는 기존 의미를 유지한다. 임의 테스트 점수 입력 기능을 구현된 것으로 추가하지 않았다. 미리보기 경로 선택/되돌림/재선택은 실제 진행기록으로 확인한다.

미연결 도착, 모든 선택지 조건 불충족, 점수 정의가 없는 선택지의 도안을 추가했다. 임의로 다음 원고 컷이나 엔딩으로 진행하지 않는다. 사용 중 점수 삭제의 위치안내를 포함한다.

## 선택지/점수 독립 조합 보완

2026-10-11. [네 조합 도안](evidence/editor-redesign/choice-score-combinations.png)을 추가했다. 기본51개 상태 중 선택지없음/점수미사용, 선택지만사용, 작품점수사용/현재컷선택지없음, 둘다사용을 명시적으로 구분한다.

| 작품 점수 | 현재 컷 선택지 | 기본 편집과 진행 |
|---|---|---|
| 미사용 | 없음 | 글·배경·인물 중심. 원고 순서/명시적 연결·엔딩으로 진행. 점수나 선택지를 자동 생성하지 않음 |
| 미사용 | 있음 | 선택 문구·도착 중심. 점수 필드는 열지 않아도 작성 가능; 만들기는 선택사항 |
| 사용 | 없음 | 현재 컷은 일반 대사/해설 또는 조건 판단 컷. 앞선 선택의 누적값 유지·점수조건 goto 가능. 현재 컷에 선택지를 강제로 만들지 않음 |
| 사용 | 있음 | 각 선택지의 효과/표시조건은 따로 선택적으로 설정. 점수가 있다고 모든 선택지에 효과/조건을 자동 주입하지 않음 |

점수 항목은 작품 수준이고 선택지는 컷 수준이다. 같은 작품 안에서도 일반 컷·선택 컷·조건 판단 컷이 섞인다. 점수를 사용하지만 현재 컷에 선택지가 없는 경우를 작품 전체에 선택지가 없는 경우와 혼동하지 않는다.

현행 점수 변화는 선택지 effects에 연결된다. 작품 전체에 선택지가 하나도 없다면 현재 계약에서 점수는 시작값을 유지하며 이를 조건으로 판단할 수 있을 뿐, 컷에 들어갈 때 점수가 자동으로 증가하는 기능은 없다. 그런 변화가 필요하면 별도 콘텐츠/실행 계약을 설계해야 한다.

기본 화면의 요약은 ‘현재 컷 선택지’와 ‘작품 이야기 점수’를 구분한다. 사용한 기능의 요약을 누르면 관련 도구로 들어가고, 미사용이면 추가 입구만 유지한다. 현재51장은 시각 도안이며 실제 개편 완료를 의미하지 않는다.

사용자에게 보이는 기능 이름과 설명은 [제품 용어 기준](editor-terminology-and-time.md#제품-용어-사용-기준--2026-10-19)을 따른다. 내부 키·현재 파일 계약과 과거 검증 기록은 용어 정리로 바꾸지 않는다.
