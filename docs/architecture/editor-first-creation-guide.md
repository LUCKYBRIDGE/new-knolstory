# 처음 만드는 놀스토리

현재 개발 중인 편집화면을 기준으로 한 짧은 안내입니다. 처음에는 글과 배경만으로 두세 컷의 이야기를 만들어 보세요.

## 1. 새 작품 만들기

서재에서 **책 찾기·추가 → 새 작품 만들기**를 엽니다. 제목을 쓰고 **새 작품 생성**을 누르면 첫 컷을 바로 쓸 수 있습니다. 표지와 이야기 기획은 나중에 설정에서 정해도 됩니다.

## 2. 첫 컷 쓰기

현재 컷의 **글상자 글**에 첫 문장을 씁니다. 대사라면 화자 이름도 입력할 수 있습니다. **배경 이미지 찾기**에서 그림을 고르고 적용하면 현재 컷의 장면을 볼 수 있습니다.

휴대폰에서는 세로로 글을 수정하세요. 키보드가 열리면 현재 컷을 중심으로 편집하고, 미리보기 좌우 화살표로 이미 있는 앞뒤 컷을 오갈 수 있습니다.

## 3. 다음 컷 이어 쓰기

**설정 → 컷 추가**를 누릅니다. 현재 컷 뒤에 빈 컷이 생깁니다. 글을 쓰고 배경을 고르는 과정을 반복하세요. 이미 있는 컷은 상단의 **현재 장과 컷 이동**에서도 선택할 수 있습니다. 새 장은 **설정 → 보기 설정 → 장 추가**에서 만듭니다.

## 4. 직접 읽어 보기

현재 컷의 **재생**을 눌러 장면을 읽어 봅니다. 편집으로 돌아오려면 무대 오른쪽 위의 **편집으로 돌아가기**를 누릅니다. 읽기 메뉴의 **이 컷 편집하기**도 같은 동작입니다. 소리와 움직이는 연출도 재생에서 확인합니다.

## 5. 작품 파일 저장하기

**설정 → 작품 파일 저장**을 눌러 기기에 `.knolstory` 파일을 보관하세요. 지원하는 브라우저에서는 선택한 파일에 다시 저장하고, 다른 브라우저에서는 새 파일을 다운로드합니다. 다운로드 방식이라면 브라우저의 다운로드 목록에서 완료와 파일 위치를 확인하세요.

화면의 **임시 보관됨**은 브라우저 안의 보조 보관 상태입니다. 작품 파일 저장을 대신하지 않습니다. 온라인 업로드도 작품 파일 저장과 별개입니다.

작품 파일을 새로 내려받으려면 같은 설정의 **작품 파일 내보내기**를 사용할 수도 있습니다. 내려받은 파일도 다시 열어 이어 쓸 수 있습니다.

## 6. 다시 열어 이어 쓰기

서재의 **책 찾기·추가 → 작품 파일 가져오기**에서 저장한 파일을 고릅니다. 가져오기 내용을 확인하면 독립된 내 사본으로 열 수 있습니다. 작품 정보 화면이 열리면 **현재 컷 쓰기**를 눌러 편집을 이어 가세요. 다른 컴퓨터로 옮길 때도 이 작품 파일을 가져가세요.

인물·음향·연출·선택지·점수·분기조건이 필요해지면 **설정 → 편집 설정**에서 원하는 기능만 켜세요. 기능을 꺼도 이미 작성한 내용은 유지됩니다. 음향과 연출을 함께 배치하는 통합 시간축은 태블릿·PC에서 사용할 수 있습니다.
