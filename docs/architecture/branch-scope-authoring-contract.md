# 실제 선택에 따른 연출·소리 조건

기준일2026-10-14. [ADR0022](../decisions/0022-branch-conditioned-direction.md)의 저작 계약이다. StoryDocument가 조건을 보관하고 Runtime Core가 실제 읽기 기록으로 해석한다. Ren’Py에는 조건을 제거한 RuntimeScene만 전달한다.

## 저작과 형식

StoryDocument schema8의 효과 cue, 재생 동작의 음악/주변 소리 cue, 개별 효과음 cue에 선택적 `branchCondition: {sourceLineId, choiceId}`를 둔다. 장 기본 소리에도 같은 계약을 적용한다. 두 항목은 존재하는 갈림길 컷과 그 컷의 선택지 ID를 가리키는 길이200 이하 비어 있지 않은 문자열이다. 임의 항목·부분 참조·유지/정지 동작의 조건은 거부한다. 하나의 cue에 하나의 조건을 두며 복합 논리 편집은 이번 범위에 넣지 않는다.

표시 문구·도착 컷을 바꿔도 선택지 ID가 유지되면 조건은 유지된다. 같은 컷에 합쳐지는 여러 선택지를 구분한다. 정적 도달 가능성을 저작 허용 조건으로 쓰지 않는다. 참조된 선택지/갈림길의 제거 또는 진행 방식 변경은 참조를 먼저 해제해야 한다. 삭제되는 컷이 소유한 cue 자체의 참조는 삭제를 막지 않는다.

archive formatVersion2/API payloadVersion1/JSONB 저장 envelope1/RuntimeScene 버전은 유지한다. workbook8의 `presentationEffects`, `audioTracks`, `audioSounds` 일반 열은 `branchConditionPresent`, `branchSourceLineId`, `branchChoiceId`다. 조건 없음은 false와 미설정 ID, 있음은 true와 두 ID다. 원고를 숨긴 payload는 추가하지 않는다. Excel·Google 시트는 이 공통 양식을 사용한다.

문서1–7과 workbook2–7은 기존 저작 데이터·자산·무대·흐름·종료 컷을 보존해 현재 버전으로 올린다. 구버전 선언에 실제 조건 데이터를 넣으면 거부한다. 기존 JSONB snapshot은 원본 저장 콘텐츠의 fingerprint를 검증한 다음 문서를8판으로 올린다. 저장된 원본이나 fingerprint를 새 버전으로 덮지 않는다. 읽기 선택 기록·편집 방문 경로·기기 UI는 작품 파일에 들어가지 않는다.

## 실제 읽기 의미

현재 cue 진입 이전에 방문한 참조 갈림길의 **가장 최근 방문**에서 해당 선택지를 실제로 고른 경우에만 cue를 시작한다. 같은 목적지라도 선택지 ID가 다르면 조건은 다르다. 선택 기록이 없거나 갈림길의 현재 방문에서 아직 고르지 않았으면 조건은 거짓이다. 조건부 작품의 읽기 복원은 필요한 선택 기록을 목적지로 추정하지 않는다.

cue 시작 컷/실제 장 진입에서 거짓이면 건너뛴다. 이후 조건이 참이 되어도 이미 지나온 cue를 뒤늦게 시작하지 않는다. 다시 시작 위치에 진입하면 새 기록으로 평가한다. 이어지는 효과·연속 소리는 참조 갈림길 재방문 대기 또는 다른 선택으로 조건이 거짓이 되면 해당 cue만 끝낸다. 관련 없는 기존 연출/소리는 건너뛴 조건부 cue 때문에 사라지지 않는다. 기존 종료 컷 포함·우회·재진입과 일반 재생/유지/정지 의미는 유지한다.

효과음은 실제 컷/장 진입 때 조건을 확인한 목록만 재생한다. 작가가 지정한 대기 시간·음량·목록 순서는 그대로다. 이 조건은 선택지 자체의 표시 조건이나 선택 점수와 별개이며 점수 없는 작품도 사용할 수 있다.

## 편집과 검증

조건은 추가 편집의 해당 cue 상세에 한 선택기로 둔다. 기본 글쓰기 화면에 조건 도구를 상시 펼치지 않는다. ‘모든 갈래’로 조건을 해제하고 기존 효과/소리별 변경 취소로 되돌릴 수 있다. 선택한 조건의 ‘갈림길부터 재생’은 그 컷에서 정상 Core 읽기를 시작한다. 독자가 실제 선택해야 하며 선택/점수 기록을 만들어 넣지 않는다. 중간 컷부터의 미리보기는 이전 선택을 추정하지 않는다.

완료 조건은 같은 목적지 두 선택지, 반복/재선택/되돌림, 조건 없음/잘못된 참조, 조건부 연출·세 소리 종류, 취소·전체 원고/무대·파일/양식/JSONB·재열기·native 읽기 복귀다. 로컬 자동 검증은 [실행 기록](branch-scope-validation.md)이 소유한다. 물리 삼성 IME/학교 기기·새 외부 앱 편집·배포는 별도 목표다. Excel ChatGPT 추가 기능 연결은 사용자 결정으로 제외했다.

사용자에게 보이는 기능 이름과 설명은 [제품 용어 기준](editor-terminology-and-time.md#제품-용어-사용-기준--2026-10-19)을 따른다. 내부 키·현재 파일 계약과 과거 검증 기록은 용어 정리로 바꾸지 않는다.
