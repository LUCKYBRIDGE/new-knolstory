## 사용 범위

[Pixabay 약관](https://pixabay.com/service/terms/)은 제한 조건 아래 상업/비상업 창작물 사용을 허용한다. [라이선스 요약](https://pixabay.com/service/license-summary/)은 무료 사용·필수 출처 표시 없음·새 창작물로 편집을 설명하면서 원본과 실질적으로 같은 파일의 standalone 판매/배포를 금지한다. 놀스토리는 이야기 창작·편집·읽기 서비스다. 서비스 전체나 음원이 포함된 작품 파일을 standalone 소리 자료집으로 간주하지 않는다. 약관은 그림·글·음향 등과 결합해 새로운 창작물이 되는 사용을 구분하며, 공식 FAQ도 더 큰 작품에 포함하는 사용을 설명한다. 현재 후보는 상업 작품에서 사용할 자료로 선정한다. 다만 편집기에서 제공하는 선택용 자료의 범위는 실제 제공 방식과 약관을 별도로 대조하며, 이 확인만으로 불허·재배포 서비스라고 단정하거나 기능을 막지 않는다. 기존 직접 제작 CC0 기본 음원의 권리 분류와도 합치지 않는다.

선정 시 음원 페이지·제작자·다운로드 날짜·당시 라이선스·가능한 다운로드 증명서를 보관한다. 실제 파일을 등록한다면 hash와 출처 기록을 별도로 작성하고 재배포 허용은 따로 판정한다. 단순 음량 변경이나 길이 자르기만으로 원본 재배포 제한이 해결된다고 가정하지 않는다.
