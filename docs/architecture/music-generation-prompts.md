## 제작·가져오기 기록

길이는 서비스의 제공 옵션에 맞춘다. 짧은 클립이면 여러 변형을 만들어 고르고, 긴 곡이면 사용할 구간을 듣고 정한다. 프롬프트만으로 정확한 길이·반복 경계를 보장하지 않는다. 원본을 보관하고 편집본을 별도로 만든다. 현재 첨부 한도는 파일당 5MB, 작품 합계 20MB다.

|---|---|
| 한글 이름·범주·속성 | 평온한마을1 / 배경음 / 한국풍, 연주곡, 평온, 가야금 |
| 원래 이름·출처 | 서비스 곡 제목 / Suno 또는 Gemini(실제 제품명) |
| 제작 증거 | 생성 날짜, 모델명, 생성 ID/페이지, 사용 프롬프트, 실제 생성·다운로드 요금제 |
| 권리 증거 | 당시 약관 URL과 사본, 허용 다운로드 증거, 상업적 사용 및 공용 편집 자산 제공 범위 |
| 청취 결과 | 음성 혼입 없음, 대사와 균형, 반복 접합, 끝 잘림·큰 소리 확인 |

2026-10-10 확인한 [Suno 약관](https://suno.com/terms)은 무료/Basic 결과의 개인·비상업 사용 제한, Pro/Premier의 권리와 허용 다운로드 조건, Remix의 별도 비상업 제한을 명시한다. 유료 생성만으로 끝내지 말고 공식 채널의 허용 다운로드도 기록한다. 본 프롬프트는 Remix가 아닌 독립 생성용이다.

[Google 음악 생성 안내](https://support.google.com/gemini/answer/16901237?hl=ko)는 생성 사용법 안내이며 상업 이용·공용 자산 제공을 포괄 승인한 증거로 사용하지 않는다. Gemini 앱, AI Studio, API의 계약은 서로 구분한다. 제품·요금제·권리 확인 전 생성 파일을 `commercialUse=permitted`로 등록하지 않는다. 이 문서는 요청 문장을 준비한 것이며 실제 생성·청취·등록 완료 기록은 아니다.

사용자에게 보이는 기능 이름과 설명은 [제품 용어 기준](editor-terminology-and-time.md#제품-용어-사용-기준--2026-10-19)을 따른다. 내부 키·현재 파일 계약과 과거 검증 기록은 용어 정리로 바꾸지 않는다.
