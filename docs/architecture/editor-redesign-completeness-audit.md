# 최종 도안 누락·키보드 감사와 보완

## 2026-10-20 편집 화면 구성 완료 작업 — 검증 완료

현재 목표의 로컬 구현·검증을 완료했다. 기본편집과 글·배경·인물·음향·연출 화면은 전체 작업 영역을 반응형으로 사용하며, 컷 미리보기는16:9이고 실제 읽기는16:9/9:16을contain한다. 가로/세로 배열과 수동 설정 유지, 컷 목록·메모, 기본 화자/글 종류 입력·재생 접근, 편집/읽기 복귀 시 즉시 크기 측정, 접이식 도구의 Escape/바깥 클릭·초점 복귀를 확인했다. 최신 기준은 [DESIGN](../../DESIGN.md#기본편집의-컷-배치와-보조-공간--2026-10-20-사용자-확정), 요구별 근거와 검사 결과는 [최종 checkpoint](evidence/editor-completion-2026-10-20/checkpoint.json)가 소유한다.

사용자가 최종 확인한 이전·다음 컷의 미리보기에는 배경뿐 아니라 인물 배치·화자·첫 글상자가 포함된다. 현재 단일 Ren’Py의 기존 screen을 정지 이미지로 렌더하며 현재 컷/읽기/음향을 전환하지 않는다. 데스크톱·태블릿 세로·휴대폰 가로/세로에서 실제320×180이미지를 확인했다. 원고 변경 시 전체 이미지 지문이 바뀌고 원복 시 기존 지문으로 돌아왔다. 실제 파일 보존 대조에서 임시 글 수정 검사의 updatedAt 변화 외 모든 저작 필드·음원 참조·양식이 유지됐다. [현재 경계 계약](responsive-audio-authoring.md#인접-컷의-장면-미리보기--2026-10-20)을 따른다.

이 컴퓨터의 고정 기준 이미지431개와 승인 음원530개는 해시를 확인해 로컬로 복원했고 Git에서 제외했다. 중간에 발견한 편집 배율 잔류를 callback ref/즉시 측정과 회귀 검사로 수정했다. 브라우저 접근 차단 때문에 미뤘던 검증은 사용자 확인 후 정상HTTP탭에서 재개했다. 새 native 미리보기를 포함한 runtime build→Web build가 성공했고 전체 단위202파일1837통과/2skip, 최종 집중19·Python60·presenter20을 확인했다. 전체 E2E 일괄 성공이나 과거 배경 자료 그림만 보인 화면을 새 장면 미리보기의 완료 근거로 주장하지 않는다.

물리 기기/OS IME/스크린리더/장시간 안정성/공개 배포는 별도 범위다. 편집 구성과 후속 변경은 최신 원격 기록을 보존해 GitHub main에 반영했다. [전달 기록](evidence/editor-main-2026-10-20/checkpoint.json)에서 소스·검사·공개 배포 제외를 구분한다. 기존 원고와 사용자 파일은 보존한다. 아래 날짜별 감사는 당시 기록으로 유지한다.

같은 날 기본편집 표시 후속: 사용자 요청에 따라 ‘화자’ 이름과 ‘연결된 이미지’의 실제 이름·썸네일을 앞에 제공하고 대사/해설 선택은 접힌 ‘글 종류 설정’으로 옮겼다. 무대의 실제 화자 지정과 상속을 사용하며 등록 이름으로 이미지를 추측하지 않는다. 해설·화면 밖 목소리와 인물 이미지 연결을 구분한다. [현재 소스·화면·검증 범위](evidence/basic-speaker-display-2026-10-20/checkpoint.json). 이전 전체 검사 수치를 새 소스의 전체 실행 결과로 확대하지 않는다.

공간 배분 후속: 사용자가 화자·연결 이미지·글 종류의 큰 영역을 줄이도록 요청했다. 별도 글 종류 칸을 작은 선택칸으로 바꾸고 화자 라벨을 입력칸 옆에 배치했다. 연결 이미지는 박스 없는 작은 정보로 제공한다. 상위 편집기의 input/select 기본 여백이 이 영역에 다시 적용되지 않도록 범위를 한정해 조정했다. 실제 데스크톱 정보 영역44px, 모바일 세로/짧은 가로70px이며 입력·선택·재생 조작부는44px로 같은 높이/상단 정렬이다. [최신 소스·화면·치수 검증](evidence/basic-speaker-compact-2026-10-20/checkpoint.json)이 앞선 큰 표시 영역을 대체한다.

상단 이동 후속: 사용자 요청으로 편집 상단 우측 끝에 서재 이동 홈 버튼을 상시 제공한다. 기존 원고 보관/한글 조합 보호가 있는 이동 동작을 재사용한다. 데스크톱·휴대폰44px버튼 위치와 가로 넘침 없음, 실제 서재 이동·편집 복귀의 현재 컷/글 보존을 확인했다. [현재 근거](evidence/editor-home-2026-10-20/checkpoint.json).

2026-10-11. 이전 도안을 실제 편집 기능에 대조했다. 기본 원칙은 유지하지만 기존 이미지를 기능/기기 검증 완료라고 해석하면 안 된다. 현재 산출물은33개의 수정 도안이다. [최종 기준](editor-redesign-final.md), [상세 이미지](evidence/editor-redesign/gallery-final.html).

## 키보드 판정 수정

이전 AOSP-derived281/212/346/397px는 해당 공개 구현과 dp≈CSSpx 가정으로 계산한 가림 참고값이다. 현재 삼성/Gboard 한글 키보드의 고정 표준이나 실제 측정값이 아니다. 특히키높이와키폭을화면에맞춰늘려그린태블릿키보드는실제제조사키보드이미지라고볼수없다. 최종도안의정확한OS키보드모양/높이확정을철회한다.

현재 그림은임의키를그리는대신‘운영체제키보드영역’으로가림을표시한다. 이수치를제품의고정CSS키보드높이로사용하지않는다. 현재폰트/배경/인물/원고는보존한다. 도안의크기는available viewport가줄어드는민감도예시이며현재기기실측전의참고다.

[삼성 태블릿 공식안내](https://www.samsung.com/us/support/answer/ANS10002016/)와[Pixel Tablet 공식안내](https://support.google.com/googlepixeltablet/answer/13555948?hl=en-AU)는표준/분할/플로팅키보드를설명한다. 모드별전체하단가림/이동가능한rect가다르므로하나의높이로모든태블릿을대표하지않는다. 실제화면/크기는[실측페이지](evidence/editor-redesign/keyboard-measure.html)와기기스크린샷으로확인한뒤교체한다. 지금물리기기증거를확보했다고주장하지않는다.

현재 화면의 핵심 문제는 이름만이 아니라 기능 분류다. 한 컷 원고 작성, 현재 작품 설정, 파일 보관, 다른 작품 선택, 전문 구조 편집을 같은 상단 수준에 놓으면 사용자가 버튼을 해석해야 한다. 기본은 서재 이동·현재 작품/저장 상태·위치와 글/배경·인물이며, 작품 단위 설정과 파일 작업은 하나의 명확한 메뉴로 묶는다. 현재 글쓰기·선택지 점수 정리와 상단 작품 메뉴 통합을 구현했고 범위별 검증 기록에 연결한다. 장/컷 구성은 기존 컷 목록의 별도 작업이며 작품 설정에 새로 추가하지 않는다.

| 후속 목표 | 상태·우선순위 | 의존성 | 완료 조건 |
|---|---|---|---|
| UX-WORK-ACTIONS | 구현·범위 검증 P1 | 현재 작품 준비/파일/복구·서재 이동·저장 guard | 포괄 상단2입구를 작업 목적에 맞게 통합, 중복 서재 행동 정리, 제목/표지/기획/파일/복구 접근·편집/취소/저장/재열기·현재 컷 복귀, 기본 입력 공간 개선을 네 viewport에서 검증 |

작품 메뉴 통합은 [현재 실행 기록](editor-view-and-cut-notes-validation.md)의 최신 항목을 따른다. 이전 도안 단계·초기 구현 전 판정은 당시 기록으로 보존하며 현재 미구현 주장으로 재사용하지 않는다. 포괄 상단 명칭을 제거하는 동시에 목적별 화면·저장 실패·같은 컷 복귀를 실제로 연결한다.


## 2026-10-12 현재 입구의 목적 재확인

사용자는 ‘작품 준비/작품 관리’의 필요성과 모호한 기존 기능 자체를 다시 점검하도록 요청했다. 실제 연결을 소스 전용 독립 검토와 함께 확인했다. 예전 두 입구의 이유는 작품 내용의 부가 정보와 파일/보관 작업을 나누려는 것이었으나, 글을 쓰는 사람에게는 두 이름 모두 결과를 예측하게 하지 못했다. 필요 없는 것은 제목·표지·기획·복구 기능 자체가 아니라 포괄적인 두 상단 입구와 중복된 서재 행동이다.

| 현재 작업 | 판정 | 사용자 관점의 기준 |
|---|---|---|
| 작품 정보·표지 | 유지, 선택적 설정 | 제목·소개·지은이·표지를 고친다. 글쓰기 전에 입력할 필수 준비 절차가 아니다 |

| 창작 메모 | 유지, 글쓰기 맥락 우선 | 쓰는 중 참고하고 필요하면 해당 메모를 고친 뒤 같은 컷으로 돌아온다 |
| 이야기 점수 | 유지, 선택지 맥락 우선 | 사용할 작품에서만 점수 정의/변화/조건을 설정한다. 모든 작가에게 입력을 요구하지 않는다 |

## 2026-10-13 현재 로컬판 재분류

기본 글·인접 컷/배치·메모 참조·단일 작품 메뉴와 목적별 연출/소리/선택지/점수는 구현된 current UI로 유지한다. 옛 경로 회귀를 복원하지 않고 같은 저작 보존/저장/왕복/native 조건으로 이관했다. 선택지도 점수도 없는 경우에 선택지 도구의 점수 바로가기가 없는 것은 의도한 밀도 조정이며, 작품 메뉴의 점수 설정 접근은 유지한다.

부분이던 선택 경로 stack은 작품별 기기 UI의 실제 편집 방문/복귀로 구현했다. 전체 분류·우선순위·의존성·완료 조건과 이번 실행은 [이어가기 검증](current-ui-continuation-validation.md)이 소유한다. 남은 갈래 한정 실행·여러 컷 복사·표정 자산/동적 camera/통합 timeline, 실기기/외부 앱/서비스·배포 및 최초 Chrome 오류 원인 판정을 소급 완료하지 않는다. 외부 업로드와 별도 Web Player는 의도적 제외를 유지한다.
