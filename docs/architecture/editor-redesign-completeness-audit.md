# 최종 도안 누락·키보드 감사와 보완

2026-10-30 인물 상대 크기 후속은 [현재 수정·보존·native 검증](evidence/character-relative-size-2026-10-30/fix-checkpoint.json)을 따른다. 기존 편집 완료 근거를 인물 높이 정규화가 올바르다는 증거로 확대하지 않는다. 원고·수동 배율을 유지하며 공통 기본 크기와 파생 이미지를 보완했다.

## 편집 기능·화면 완료 판정 — 2026-10-29

현재 목표 ‘편집 기능 구현과 편집 화면 UI/UX’는 현행 사용자 확정 지원 범위에서 완료했다. 아래 요구별 구현 근거와 이후 변경 영향을 대조했고, 첫 창작·전용 도구·통합 시간축의 실제 조작과 최신 S25 키보드/가로→세로 복귀·전체 원고/파일 보존까지 확인했다. 단순히 새 결함을 찾지 못했다는 이유로 완료한 판정이 아니다. [최종 요구별 근거·현재 소스 식별자](evidence/editor-completion-audit-2026-10-29/checkpoint.json)가 이 판정의 범위를 기록한다.

전체 제품 완성·모든 기기 출시 판정은 계속 미완료다. 학교 Windows·크롬북·Android 태블릿의 실제 성능/기기 지원, 보조 기술의 실제 읽기·선택, 다른 키보드 모드는 PC-06/제품 검증 단계에 유지한다. 앞선 VoiceOver 사용 허용은 당시 시도·원상복구로 이행됐으며 다시 편집 개발의 선행 조건으로 삼지 않는다. 사람의 첫 사용성 체험과 AI 원고 활용은 이후 단계이고, 진행할 수 있도록 첫 창작 안내와 현재 파일 경로를 준비했다. 아래 날짜별 기록과 제한은 당시 범위로 보존한다.

## 전체 화면 추가 요구 — 2026-10-29

위 편집 완료 뒤 요청된 좁은 화면의 전체 화면/해제 접근을 편집 상단 바로가기로 보완했다. 설정·컷 이동·서재와 같은 줄에서44px 터치 영역을 유지하고, 읽기 메뉴에서 조작 후 초점이 사라지는 문제도 수정했다. [현재 소스·실제 S25·좁은 폭 검증](evidence/fullscreen-shortcut-2026-10-29/checkpoint.json). 기존 요구별 완료 근거를 반복 실행하거나 덮어쓰지 않고 변경된 범위를 별도 확인했다.

## 웹 편집 연결 재점검 — 2026-10-29

전체 화면·이탈 보호 추가 뒤 기본/전용/통합 화면의 수정·파일·실제 재생 복귀를 대조했다. 저장 원고의 객체 키 순서 오판, 뒤로가기 승인 후 이력 변경과 대기 중 조작 경합을 수정하고 XLSX CI timeout을 보완했다. [실행별 근거·남은 운영 경계](evidence/web-editor-connections-2026-10-29/checkpoint.json). 기존 검증과 새 실행을 합쳐 단일 전체 브라우저 통과로 표시하지 않는다.

### 남은 실제 환경 확인의 순서 — 2026-10-28

1. 실제 휴대폰의 최신 인물·음향·연출 상세 조작: 닫힌 키보드에서 현재44px 조작부와 가로 넘침을 확인하고, 글/화자/검색/숫자 입력을 선택했을 때 활성 입력이 가려지지 않는지 확인한다. 기기 잠금·다른 앱·원래 작품 상태를 먼저 확인하며 기존 파일과 원고를 보존한다.

[현재 경계 계약](responsive-audio-authoring.md#인접-컷의-장면-미리보기--2026-10-20)을 따른다.

이 컴퓨터의 고정 기준 이미지431개와 승인 음원530개는 해시를 확인해 로컬로 복원했고 Git에서 제외했다. 중간에 발견한 편집 배율 잔류를 callback ref/즉시 측정과 회귀 검사로 수정했다. 브라우저 접근 차단 때문에 미뤘던 검증은 사용자 확인 후 정상HTTP탭에서 재개했다. 새 native 미리보기를 포함한 runtime build→Web build가 성공했고 전체 단위202파일1837통과/2skip, 최종 집중19·Python60·presenter20을 확인했다. 전체 E2E 일괄 성공이나 과거 배경 자료 그림만 보인 화면을 새 장면 미리보기의 완료 근거로 주장하지 않는다.

## 키보드 판정 수정

이전 AOSP-derived281/212/346/397px는 해당 공개 구현과 dp≈CSSpx 가정으로 계산한 가림 참고값이다. 현재 삼성/Gboard 한글 키보드의 고정 표준이나 실제 측정값이 아니다. 특히키높이와키폭을화면에맞춰늘려그린태블릿키보드는실제제조사키보드이미지라고볼수없다. 최종도안의정확한OS키보드모양/높이확정을철회한다.

현재 그림은임의키를그리는대신‘운영체제키보드영역’으로가림을표시한다. 이수치를제품의고정CSS키보드높이로사용하지않는다. 현재폰트/배경/인물/원고는보존한다. 도안의크기는available viewport가줄어드는민감도예시이며현재기기실측전의참고다.

[삼성 태블릿 공식안내](https://www.samsung.com/us/support/answer/ANS10002016/)와[Pixel Tablet 공식안내](https://support.google.com/googlepixeltablet/answer/13555948?hl=en-AU)는표준/분할/플로팅키보드를설명한다. 모드별전체하단가림/이동가능한rect가다르므로하나의높이로모든태블릿을대표하지않는다. 실제화면/크기는[실측페이지](evidence/editor-redesign/keyboard-measure.html)와기기스크린샷으로확인한뒤교체한다. 지금물리기기증거를확보했다고주장하지않는다.

## 2026-10-12 현재 입구의 목적 재확인

## 2026-10-13 현재 로컬판 재분류
