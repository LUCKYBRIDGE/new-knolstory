# 다음 세션 목표 프롬프트

제품 완성 작업의 **고정 진입점**이다. 날짜별 새 프롬프트를 만들지 않고 아래 소유 문서를 갱신한다.

| 읽을 문서 | 역할 |
|---|---|
| [제품 완성 목표](product-completion-goal-2026-10-15.md) | 전체 범위·보존/제외·완료 기준·반복 방지 규칙 |
| [제품 완성 실행 계획](product-completion-plan.md) | 현재 재개 지점·단계 간 큐·의존성·다음 행동·미결 질문 |
| [STATUS](../../STATUS.md) | 현재 제품 구현 상태와 열린 문제 |

AGENTS의 필수 읽기 순서를 지킨 뒤 현재 작업에 연결된 세부 계획/계약/source/최신 증거만 읽는다. 이전 [2026-10-13 인수인계](next-session-goal-2026-10-13.md)는 역사/결정 근거가 필요할 때만 참고한다. 목표·상태·검증 기록을 여러 파일에 복제하지 않는다.

새 세션에서 아래만 붙여 넣는다.

```text
/goal docs/architecture/next-session-goal-prompt.md를 읽고 뉴놀스토리 제품 완성을 진행해줘. 연결된 목표와 단일 실행 계획의 재개 지점부터 이어서, 완료 작업·유효한 검증은 반복하지 말고 의존성이 풀린 다음 작업을 구현·검증해줘. 미커밋 변경과 전체 목표를 보존하고, 필요한 결정만 묶어 질문하며 독립 작업은 계속해줘.
```

사용자에게 보이는 기능 이름과 설명은 [제품 용어 기준](editor-terminology-and-time.md#제품-용어-사용-기준--2026-10-19)을 따른다. 내부 키·현재 파일 계약과 과거 검증 기록은 용어 정리로 바꾸지 않는다.
