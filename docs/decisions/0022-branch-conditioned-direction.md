# ADR0022 — 실제 선택 기록으로 연출·소리 조건 해석

날짜2026-10-14. 상태: 승인된 제작 UX 목표의 구현 결정.

## 문제

여러 선택지가 같은 컷으로 합쳐질 수 있으므로 컷 경로만으로 작가가 지정한 갈래별 연출·소리를 구분할 수 없다. 편집에서 목적지를 조건으로 추정하거나 Ren’Py가 StoryDocument를 다시 해석하면 읽기 복원·되돌림 및 같은 선택지 ID의 보존 의미가 달라진다.

## 결정

StoryDocument schema8의 cue에 갈림길 컷 ID와 선택지 ID의 한 쌍을 선택적 조건으로 둔다. Core는 기존 실제 choiceHistory와 가장 최근 갈림길 방문으로 시작·지속 여부를 판단한다. Ren’Py는 해석된 효과/소리만 재생한다. 편집 미리보기는 정상 읽기를 갈림길부터 시작하며 선택/점수 기록을 만들지 않는다.

workbook8은 일반 열로 같은 참조를 편집한다. 기존 문서·양식의 명시적 migration과 원본 JSONB fingerprint 확인을 유지한다. archive2/API1/JSONB envelope1/RuntimeScene 버전은 바꾸지 않는다. 점수 없는 선택지도 지원한다. [상세 계약](../architecture/branch-scope-authoring-contract.md)을 따른다.

## 결과와 범위

같은 도착 컷·반복·재선택에서도 선택지의 실제 ID를 보존한다. 조건 없는 기존 작품의 해석은 유지하며, 조건부 작품의 복원에서 필요한 기록을 추정할 수 없다. 여러 조건을 묶는 논리 도구·모든 Ren’Py 기능 도입·별도 Web 플레이어는 추가하지 않는다. 실제 외부 앱·물리 기기·서비스 배포는 로컬 코드/codec/native 검증과 구분한다. Excel ChatGPT 추가 기능 연결은 이번 사용자 결정으로 제외한다.
