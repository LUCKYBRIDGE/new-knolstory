# ADR 0026 — 정적 읽기·편집과 선택적 온라인 API

Status: Accepted direction (2026-10-29). 구현·공개 배포·권리 승인과 구분한다.

## 근거와 대체 범위

사용자가 제공한 [웹 배포·공용 자산·작품 데이터 제안](../architecture/evidence/static-delivery-2026-10-29/proposal-source.md)을 현재 제품 방향에 맞게 수용한다. 이 문서는 제안 원문 보존이며 실행 큐의 소유자는 [단일 실행 계획](../architecture/product-completion-plan.md)이다. 원문의 숫자·배포 상태는 역사적 입력으로 보고 실제 인벤토리와 응답으로 검증한다.

[ADR0023](0023-mac-mini-docker-and-linked-login.md)의 Mac mini 호스팅 책임을 부분 대체한다. 목표 구조에서 공개 웹앱·공용 자산·공개 기본 원고·Ren’Py 실행 파일은 독립 정적 전달 계층이 맡고 Mac mini Docker/PostgreSQL은 온라인 계정·권한·개인 작품 문서·버전 API에 집중한다. 카카오 가입과 연결된 Google 로그인 정책, 기존 DB/자료 보호, [ADR0025](0025-legacy-server-replacement.md)의 구 서버 교체 방향은 바꾸지 않는다. 현재 운영 도메인을 이 ADR 작성만으로 전환하지 않는다.

## 유지하는 저작·재생 경계

- 작품 저장의 기본은 실제 `.knolstory`/`.shortstory` 파일이다. 임시 보관은 복구 보조이고 온라인 동작은 업로드다.
- StoryDocument와 Asset ID·Flow·StageComposition·오디오 cue가 원본이다. 공용 그림/음원 원본을 개인 작품 DB나 매 작품 파일에 중복 첨부하지 않는다.
- Runtime Core가 해석하고 Ren’Py Web이 실제 이야기 장면을 그린다. 별도 Web Stage를 만들지 않는다. 숏스토리 인쇄 예외는 유지한다.
- 계정 API 장애가 공개 작품 읽기·로컬 편집·파일 저장을 막지 않는 것이 목표다. 이미 로드된 편집기의 오프라인 보존과 최초 정적 접속·전체 읽기는 별개로 검증한다.
- 직접 추가하는 개인 미디어는 현행 catalog-only 제공 범위를 이 결정으로 개방하지 않는다. 향후 권한·보존·파일 계약을 별도로 정한다.

## 2026-10-30 Pages 업로드 실행 승인

사용자가 모든 작품·편집의 공통 적용과 GitHub main 반영을 확인하고, 이미지·음향을 포함한 서비스 자산 전체를 Cloudflare Pages에 올리도록 명시 요청했다. 이전의 외부 업로드 미승인 상태를 이 범위에서 대체한다. 실제 Pages 프로젝트·배포 ID·파일 해시·HTTP 응답·실제 재생을 확인해 배포 결과를 기록한다. 기존 legacy Pages 프로젝트를 Next 프로젝트로 추정해 덮어쓰지 않는다.

이 요청은 현재 서비스 제공 범위의 게시 행동 승인이다. 미확인 원본의 저작권·상업 배포 권리를 자동으로 `permitted`로 바꾸는 결정은 아니다. 기존 출처·고지·조건부 음향 기록과 공개 전 감사 보고서는 그대로 보존한다. 장면에 결합된 음원 제공과 참조형 작품 파일 정책을 유지하며, 원음 자료실이나 독립 다운로드 기능을 추가하지 않는다. 기술적 결함·누락·개인 파일 혼입·오래된 해시·허용 크기 초과는 업로드 전에 해소한다.

정적 읽기·로컬 편집·실행 파일은 같은 Pages 출처에서 검증한다. 기존 운영 origin의 로그인·업로드 API는 별도 같은 출처 프록시가 필요하므로 단순 API URL 변경이나 기존 도메인 전환으로 훼손하지 않는다. 운영 origin을 전환할 때는 API·cookie·CSRF·OAuth callback 연결을 함께 확인한다. 이 절만으로 DNS/API 연결이 완료된 것으로 판정하지 않는다.

## 정적 전달 결정

Cloudflare Pages를 우선 검토하되 R2는 필수가 아니다. 실제 파일 크기·수·캐시·권리·초기 전송량을 측정한 뒤 결정한다. [Pages 공식 제한](https://developers.cloudflare.com/pages/platform/limits/)의 파일당25MiB보다 큰 파일을 그대로 업로드할 수 없다. 최초 조사 당시 `runtime/game.zip`은37,680,521바이트로 Pages 단독 후보의 크기 조건을 넘었다. 그때의 [인벤토리 근거](../architecture/evidence/static-delivery-2026-10-29/checkpoint.json)는 보존하며, 다음 후속 패키지 결과가 현재 크기 판정을 대체한다. 거대한 다운로드용 `runtime.zip`을 웹 실행 필수 파일로 혼동하지 않는다.

Ren’Py iframe과 브리지는 현재 같은 출처 메시지·부모 접근 계약을 사용한다. `/runtime/` 프레임의 출처를 임의로 바꾸지 않는다. 별도 저장소를 사용하더라도 같은 출처 경로에서 바이트를 전달하는 방법과 캐시·범위 요청을 검증하는 것이 우선이다. Web 이미지 src만 바꿔 Ren’Py 자산 전달도 바뀌었다고 판정하지 않는다. 프레임워크·미디어·런타임 번들의 출처와 라이선스는 각각 확인한다.

## Pages 단독 크기 조건을 충족한 후속 패키지 — 2026-10-29

공용 음원을 다시 인코딩하지 않고 긴 배경음·환경음25개를 필요할 때 받는 방식으로 옮겼다. 짧은 효과음36개는 실행 묶음에 유지한다. 기존 package 음원61개의 원본 SHA-256과 그림421개의 바이트는 바꾸지 않았으며, 작품의 Asset ID·재생/배치 설정과 같은 출처의 Ren’Py 프레임 계약도 유지한다. 이 구분은 초기 실행 묶음을 줄이기 위한 전달 정책이며 음악 품질을 낮추거나 원고를 변환하는 정책이 아니다.

그 결과 `game.zip`은37,680,521→13,491,570바이트로64.19% 줄었다. 실제 정적 사이트 후보는1,528개 파일이며 별도 객체 저장 파일은0개다. 가장 큰 필수 파일인 `runtime/renpy.wasm`은21,586,559바이트로25MiB 아래다. **현재 후보는 Pages 단독의 파일 크기 조건을 충족하므로 R2 없이 준비를 계속할 수 있다.** R2는 필요성이 확인될 때 선택하는 대안으로 유지한다. [패키지·바이트 보존·검증 범위](../architecture/evidence/static-delivery-2026-10-29/pages-audio-checkpoint.json).

별도 API를 두지 않은 Pages 전용 로컬 정적 후보에서 최종 브라우저 검사5개가 함께 통과했다. 여기에는8판본의 실제 Ren’Py 진입과 다음 컷 이동, 놀스토리/숏스토리의 실제 다운로드와 새 환경 재열기가 포함된다.8판본의 모든 선택 갈래·엔딩을 끝까지 검사한 결과는 아니다. 이 중 음향 검사2개에서 OGG·MP3 배경음의 실제 재생 위치가800ms 구간의 시작으로 두 차례 이상 돌아오는 것, 다음 컷에서도 재시작 없이 유지되는 것, 정지와 짧은 효과음 재생을 확인했다.

이 결과는 파일 크기와 로컬 동작의 기술적 후보 판정이다. 자산 권리·런타임 번들의 출처 검증, 캐시/실패 복귀, 실제 Pages 업로드·공개 도메인 전환, 느린 망과 목표 실기기 검증을 통과한 공개 출시 판정은 아니다. 외부403 응답으로 확인하지 못한 현재 제공 호스트/경로도 미확인으로 유지한다.

## R2 비용 조건 — 2026-10-29 사용자 후속 결정

사용자는 ‘R2도 비용이 안 든다면 괜찮다’고 답했다. 무료 범위 안의 R2 사용을 후보로 수용하되 무조건 무료이거나 유료 사용/계정 변경까지 승인된 것으로 해석하지 않는다. R2를 필수로 확정하거나 Pages 단독 후보를 폐기하지 않는다. [공식 요금](https://developers.cloudflare.com/r2/pricing/)을 확인한 현재 Standard 무료 구간은 월10GB-month 저장·Class A100만회·Class B1,000만회이며 인터넷 전송료는 무료다. Infrequent Access에는 이 무료 구간이 적용되지 않고 연결된 다른 유료 서비스는 별도다.

최초 조사 당시 전체 로컬 정적 산출물 약0.81GB와 실행 묶음 약37.7MB는 저장 용량 기준으로 무료 구간 아래였지만, 계정의 다른 버킷·과거 버전·백업과 월 요청량은 미확인이다. 후속 Pages 단독 크기 조건 충족은 위 절의 현재 근거를 따르며, 이 비용 검토만으로 R2 사용을 확정하지 않는다. 실제 계정 사용량·캐시 요청·같은출처 라우팅(Workers/Functions 등)의 별도 비용 조건을 확인하기 전 ‘월0원 보장’으로 안내하지 않는다. 알림은 자동 과금 차단 장치로 간주하지 않는다. 외부 버킷/키 생성·업로드·결제 변경·운영 전환은 아직 수행하지 않는다.

## 배포 전 선행 조건

빌드 산출물의 ID·URL·크기·SHA-256·MIME·사용 작품·권리·Git 추적 여부를 읽기전용으로 대조한다. 누락·오래된 권리 해시·개인 원고/진단·미확인 재배포·호스팅 크기 제한은 차단 사유다. `scene-integrated` 음원 사용과 원음의 독립 공개 재배포 허가는 같은 것이 아니며 기존 권리 검사를 우회하지 않는다. 런타임 ZIP에 포함된 그림도 별도 공개 승인으로 간주하지 않는다.

실제 자산 패키지와 URL/캐시 후보가 성립한 뒤, 별도 API가 꺼진 정적 환경에서8판본 전체 갈래·새 작품의 편집/저장/다른 환경 재열기/실제 재생·대상 기기/느린 망을 확인한다. 기존 유효한 편집 근거는 재사용하되 정적 공개 준비 완료로 확대하지 않는다. DNS·Tunnel·운영 전환·외부 자산 업로드는 검토된 산출물과 필요한 권한이 갖춰진 마지막 단계에서 수행한다.
