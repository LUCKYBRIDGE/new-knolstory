# ADR0020 — 공용 편집 음원의 권리 승인과 제외

부분 대체: 이후 사용자 결정과 [ADR0021](0021-scene-integrated-audio-rights.md)이 CC0-only/14개 일괄 제외를 장면 결합 조건부 사용으로 바꿨다. 아래는 당시 판단의 기록이다. 원본/해시·미확인 항목·기존 ID/제외 안내 검사는 유지한다.

상태: Accepted. 날짜: 2026-10-10. 사용자 결정: 상업적 놀스토리 서비스에 이용할 수 있는 자료만 제공하고 아닌 것은 제외한다.

완성된 창작물에 사용하는 권한만으로 공용 원음 선택·미리 듣기·제공 권한을 추정하지 않는다. 현재 기본 자료는 직접 제작/외부 CC047개로 제한한다. Pixabay Content License14개는 현재 서비스 범위가 확인되지 않아 제외한다. 이후 개별 계약·권리 증거를 확인하면 새 승인 절차로 변경할 수 있다.

공용 승인 목록은 ID·경로·원본 hash·상업·재배포·공용 편집 제공 범위와 근거를 기록한다. 빌드 시 실제 원본과 ZIP·provenance가 일치해야 한다. 제외된 기존 ID는 문서에서 보존하고 자동 대체하지 않으며, UI에서 안내하고 재생 경로에서는 제외한다. 사용자 첨부 파일의 로컬 편집·보관은 이 공용 승인과 구분한다.

ADR0019의 검색 속성/출처 보존과 workbook5는 유지한다. 그 문서의 이전 Pixabay 공용 등록 상태와 허용 경로는 현재 제외 결정으로 부분 대체한다. archive2/StoryDocument6/workbook5/JSONB1 변경은 없다. 서버·공유·학급 운영 정책을 여기서 결정하지 않는다.

정식 절차·현재 목록·검증·후속은 [공용 음원 권리 계약](../architecture/audio-service-rights.md)이 소유한다.
