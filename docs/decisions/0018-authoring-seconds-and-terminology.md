# ADR 0018 — 편집 시간은 초, 내부 시간과 ID는 보존

Status: Accepted for current authoring scope (2026-10-10 사용자 결정).

음악은 **배경음**으로 통일하고, 어려운 편집 용어를 쉬운 이름으로 바꾸며 편집 중 검색 가능한 용어 안내를 제공한다. ‘주변 소리(환경음)’, ‘말하는 인물’, ‘작품 자료’, ‘인물 배치’, ‘추천 설정’, ‘하나라도 만족’, 점수의 ‘이 값으로 바꾸기’를 기준으로 사용한다. 원고·이름·자유 문구·자료 ID와 이야기 단위 장/컷은 보존한다.

화면 시간 입력과 새 Excel/Google 시트 시간 열은 **초**를 기준으로 한다. 0.1초·0.23초처럼 소수를 입력한다. 내부 StoryDocument6의 `*Ms` 필드, archive2, RuntimeScene/Core/Ren’Py 계약은 바꾸지 않는다. 표시 이름·사용자 단위와 콘텐츠의 재생 의미를 분리한다.

새 workbook4의 시간 열은 초다. 기존 workbook2/3은 당시 단위ms를 명시적으로 변환해 가져오며, 선언 버전/metadata 불일치와 알 수 없는 버전은 거부한다. 이전 값230을230초로 읽지 않는다. 둘째 행 내부 키는 유지하고 한글 열 제목·메모에 초 단위를 명시한다. 십진수 문자열 소수점 이동으로 기존 정밀 값과 0/미설정 차이를 보존한다. 이전 한글 선택 값과 탭 이름은 각 항목에 한정한 별칭으로 읽으며 중복된 이전/현재 탭은 거부한다.

배경음과 주변 소리는 내부 연속 재생 자료 종류를 유지하면서 사용자 선택 목록을 구분한다. 기본 자료의 분류는 현재목록의 안정적인ID로 정한다. 사용자 소리 파일은 작품의 용도에 맞춰 선택할 수 있고, 기존 선택을 자동 바꾸지 않는다.

이 결정은 [ADR0017](0017-story-score-authoring.md)의 당시 workbook3 버전만 부분 대체한다. 점수 규칙·Core 소유·문서6/archive2는 유지한다. [용어·시간 계약과 검증](../architecture/editor-terminology-and-time.md), [기본 소리 목록](../architecture/audio-inventory.md).
