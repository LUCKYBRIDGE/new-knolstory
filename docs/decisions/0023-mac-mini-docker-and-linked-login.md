# ADR 0023 — Mac mini Docker와 카카오 가입·Google 계정 연결

Status: Accepted for hosting and login identity policy (2026-10-16). 실제 배포·계정/학급/공유/보관 정책 전체 승인으로 확대하지 않는다.

2026-10-17 부분 대체: 기존 서버의 장기 보존/병행 운영 방향은 [ADR0025](0025-legacy-server-replacement.md)의 Next 교체·구 서버 폐기 결정으로 대체한다. 아래는 결정 당시 기록이며, 로그인 정책은 그대로 유효하다. 영구 삭제는 정확한 대상의 별도 최종 확정 후 실행한다.

## 사용자 결정

- 서버는 구 놀스토리처럼 현재 Mac mini의 Docker에서 구현한다.
- 카카오 로그인을 통해 회원가입과 로그인을 제공한다.
- 가입한 계정에서 Google 계정을 연결할 수 있다.
- 연결 완료 후 Google 로그인도 같은 놀스토리 계정에 로그인해야 한다.

## 적용

카카오와 연결된 Google은 별도 작품 소유자를 만들지 않고 같은 내부 계정 ID를 참조한다. 작품·학급·제출 관계는 내부 계정에 연결한다. 연결하지 않은 Google 신원은 신규 회원가입을 만들지 않는다. 계정 연결은 기존 계정의 인증된 세션과 연결할 Google 본인 인증을 모두 확인한 명시적인 동작이다. 이메일 일치만으로 자동 연결/병합하지 않는다. 동일한 Google 신원을 두 계정에 연결할 수 없으며, 연결 충돌·동시 요청·실패 시 기존 계정과 작품을 보존한다.

OIDC 제공자 subject 식별과 내부 계정 ID를 분리한다. 실제 OAuth 토큰/issuer/audience/nonce/state·세션·CSRF·요청 제한 구현과 end-to-end 검증이 필요하며, 순수 계정 연결 테스트만으로 로그인 완료를 주장하지 않는다. 실제 provider app 설정·비밀값·외부 callback 변경은 검토 가능한 구현 후보에 대해 적용 경계를 따른다.

Mac mini의 기존 놀스토리 Docker 컨테이너·네트워크·DB·볼륨·tunnel은 유지한다. Next는 전용 Compose 프로젝트·DB·네트워크·볼륨으로 검증하고, 테스트 DB 포트는 호스트에 공개하지 않는다. 기존 DB/사용자/자산을 자동 이전하거나 공유하지 않는다. 실제 서비스 공개·도메인 연결·운영 전환은 별도 출시 검증과 승인을 따른다.

## 남은 결정

교사 권한 부여·학생 학급 참여 승인·제출/재제출·링크 공유/공개·삭제/탈퇴/백업 보관 기간은 이 결정에 포함하지 않는다. 공개 링크 의미는 설명했지만 허용 범위는 아직 답변 대기다. 카카오 가입·연결 후 Google 로그인 결정을 다시 질문하지 않는다.

이 ADR은 [ADR0011](0011-legacy-freeze-and-forward-port.md)의 추천 서버안 중 호스팅 및 로그인 제공자 부분을 현재 사용자 결정으로 구체화한다. 원본 저작 SSOT와 [저장 계약](../architecture/authoring-storage-contract.md), [실행 계획](../architecture/product-completion-plan.md)의 전체 범위를 유지한다.
