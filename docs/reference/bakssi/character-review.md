# 박씨전 인물별 얼굴과 신체 비율

[현재 등록 인물 비교판](bakssi-cast-before-review.jpg)은 2026-11-28 기본 그림과 혼례복을 확인하는 자료다. [사용자가 고른 박씨 세 그림](bakssi-face-comparison.jpg)을 박씨의 얼굴 기준으로 사용한다. 허물 전 평상복과 혼례복, 허물을 벗지 않는 갈래는 같은 얼굴이다. 허물을 벗은 뒤에도 목 아래의 체격은 같은 사람으로 이어진다.

## 닮은 인물부터 검토

| 현재 겹치는 인물 | 기본 그림을 다시 그릴 때 나눌 특징 |
| --- | --- |
| 계화·바느질댁·아기 어머니 | 계화는 넓은 이마, 짧은 턱과 먼저 올라가는 한쪽 눈썹, 곧은 자세. 바느질댁은 긴 얼굴, 얇은 눈꺼풀과 입가의 잔선, 일을 살피느라 고개를 약간 숙이는 자세. 아기 어머니는 좁은 어깨, 내려가는 입매와 피곤한 눈 밑, 아기를 품은 몸의 기울기. |
| 언니·노란 댕기 아이·솔이·이웃 아이 | 둥근 눈과 옆으로 기운 얼굴이 겹친다. 언니는 긴 얼굴과 좁은 눈, 동생을 살피는 시선. 노란 댕기 아이는 둥근 턱과 두툼한 볼, 작은 체격. 솔이는 짧고 각진 턱과 짙은 일자 눈썹. 이웃 아이는 넓은 이마와 옆으로 묶은 머리. |
| 우물집 할머니·짚 엮는 할머니·계화 어머니 | 두 할머니의 웃는 입과 눈이 비슷하다. 우물집 할머니는 둥근 어깨와 넓은 볼, 입 한쪽부터 올라가는 웃음. 짚 엮는 할머니는 마른 체격, 긴 코와 오목한 뺨. 계화 어머니는 한 세대 아래로 보이는 일부 새치, 네모난 턱과 넓은 어깨. |
| 사기장이·곡식 장수·수레꾼 | 사기장이는 두꺼운 팔과 넓은 코, 낮은 무게중심. 곡식 장수는 마른 몸, 뾰족한 턱과 높이 든 시선. 수레꾼의 둥근 몸과 굵은 목은 먼저 비교 기준으로 삼는다. |
| 이시백·기홍대 | 이시백은 마른 체격, 긴 목, 말하기 전 다무는 입. 기홍대는 짧고 힘 있는 목, 곧은 눈썹과 광대, 주변을 살피는 시선. 이시백 기본 얼굴을 바꾸면 혼례복도 맞춘다. |
| 이득춘·박 처사·김자점·사신 | 먼저 머리쓰개와 수염을 가리고 본다. 이득춘은 넓은 이마와 둥근 눈, 박 처사는 마른 볼과 긴 얼굴, 김자점은 짧은 네모 턱과 낮은 눈썹, 사신은 긴 코와 한쪽이 올라가는 입매. |
| 용울대·용골대·청군 병사 | 용울대는 넓은 가슴과 짧은 턱, 용골대는 긴 얼굴과 눈 밑의 피로, 병사는 좁은 어깨와 젊은 인상. 형제는 한 특징을 공유해도 체격과 턱선이 달라야 한다. |
| 바느질댁 아이 | 다른 아이들과 얼굴이 겹치면 낮은 이마와 다문 입, 몸이 가볍게 앞으로 향하는 자세를 시험한다. |

표는 재생성 후보와 출발점이다. 사람마다 얼굴 특징 두 가지와 체격·자세 한 가지를 먼저 정한다. 얼굴형과 몸의 차이가 실제 장면에서 보이면 기존 그림을 활용한다. 기존 세 작품에서 참고한 먹선·한지 질감·수채와 복식은 이어 간다. 기쁨·분노 같은 감정은 인물마다 다른 눈·입·손의 움직임으로 표현한다.

## 동작이 바뀌어도 같은 체격 유지

| 기준 전신에서 먼저 기록할 항목 | 후보를 비교하는 방법 |
| --- | --- |
| 얼굴 | 정수리부터 턱까지의 실제 머리 높이, 광대 폭, 눈 간격, 눈썹과 눈·코·입의 상대 위치를 기록한다. 관모와 댕기는 머리 치수에서 제외한다. 같은 각도의 얼굴을 같은 화면 크기로 비교한다. 고개를 돌리거나 숙였을 때의 원근 변화는 시점으로 설명할 수 있어야 한다. |
| 몸통 | 어깨 관절 사이 폭, 목밑부터 골반 중심까지의 길이, 가슴과 골반 폭을 기록한다. 도포나 치마 자락의 끝은 몸통의 너비로 재지 않는다. 옷에 가려진 관절은 밑그림에서 추정하고 보이는 항목부터 확인한다. |
| 팔다리 | 어깨–팔꿈치–손목과 골반–무릎–발목을 짚어 위팔·아래팔, 허벅지·종아리 길이를 각각 비교한다. 손목에서 손끝까지, 뒤꿈치에서 발끝까지의 크기도 본다. 한 관절이 가려지면 보이는 손발과 반대편을 먼저 비교하고 애매한 경우 같은 각도 후보를 한 장 더 만든다. |

1. 인물마다 정면에 가까운 평상복 전신을 먼저 승인하고, 같은 그림 위에 관절과 치수를 표시한 제작용 비교판을 보관한다. 머리 높이와 어깨 폭 같은 기준은 해당 인물의 값으로 기록한다. 아이·성인, 마른 사람·통통한 사람이 같은 머리 대 몸 비율을 공유할 필요는 없다.
2. 새 자세는 승인 전신을 첫 참조로 두고 동작과 각도만 지정한다. 눈에 보이는 신체 부위의 크기를 같은 배율로 대조한다. 좌우로 손을 뻗었을 때 생기는 실루엣 폭과 몸 자체의 어깨 폭을 구분한다. 방향이 같은 부위의 길이나 폭이 달라 보이면 기준 그림을 겹쳐 확인하고, 원근으로 설명하기 어려운 차이는 다시 그린다.
3. 앉기·웅크리기·실제 고개 숙이기는 무릎·엉덩이·허리에서 몸이 접힌다. 등록할 때 머리와 손의 배율은 유지하고 자세로 낮아진 정수리 높이를 그대로 둔다. 현행 등록기의 알파 높이 정규화에서 앉은 그림에 기존 서 있는 높이를 그대로 넣으면 몸을 크게 확대한다. 자세 자산을 등록할 때는 몸체와 머리의 실제 배율에 맞는 자세별 목표 높이를 레시피에 기록하고, 발이나 좌면의 접지 위치는 실제 무대에서 확인한다. 한 축만 늘려 치수를 맞추지 않는다.
4. 숫자 검사는 [그림 제작 기준](art-production.md)의 투명 800×1200 캔버스·여백·발 기준과 등록 치수를 확인한다. 얼굴이나 관절 비율이 맞는지는 별도의 비교판으로 검수한다. 이름과 옷 색을 가린 얼굴 확대, 전신 실루엣, 실제 가로·390px 세로 화면에서 확인한다.
5. 승인된 기본 전신의 PNG를 표정·혼례복·숏스토리 삽화에 사용한다. 바뀐 인물이 들어간 기존 그림을 찾아 필요한 그림만 함께 교체한다. 기록에는 Asset ID, 얼굴과 체격의 식별점, 기준 전신과 동작 비교판, 교체한 파생 그림, 가로·세로 확인 결과를 남긴다.
