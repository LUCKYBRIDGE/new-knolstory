# 박씨전의 그림으로 나만의 이야기 쓰기

숏스토리에서 **삽화 고르기 → 자유 창작 → 작품 박씨전**을 선택하면 다음 그림을 찾을 수 있다. ‘풍경’은 [이어지는 두 장면](creative-illustration-review.jpg)의 공통 소품이다. ‘이어지는 사건’에서 ‘나무 아래의 풍경’을 고르면 발견 장면과 문턱 장면을 순서대로 볼 수 있다. 학생은 사용할 그림과 쪽 순서를 직접 정한다.

| 그림 | 쓸 수 있는 사건 | 검색어 |
| --- | --- | --- |
| 나무 아래의 풍경 | 감나무 밑의 낯선 풍경을 발견한다. | 풍경 · 발견 · 감나무 |
| 풍경을 들어 올린 문턱 | 같은 풍경을 들고 문안으로 귀를 기울인다. | 풍경 · 파란 끈 · 탐색 |
| 개울 위의 느슨한 널빤지 | 어른과 아이가 개울을 건널 방법을 찾는다. | 협력 · 널빤지 · 개울 |
| 상 위에 놓인 봉투 두 장 | 어느 봉투를 살펴볼지 의견이 나뉜다. | 편지 · 봉투 · 갈등 |
| 그릇에 찍힌 잎 자국 | 젖은 그릇에 남은 우연한 자국을 본다. | 그릇 · 잎 자국 · 실수 |
| 개울에 띄운 풀잎 배 | 자매가 떠가는 풀잎 배 두 척을 지켜본다. | 풀잎 배 · 경쟁 · 개울 |

놀스토리의 인물 고르기에서는 **작품 박씨전**, **장면 용도 자유 창작**과 동작 검색어를 사용한다. [기준 전신과 새 동작 비교판](creative-character-action-review.jpg)에서 계화의 바구니, 기홍대의 듣기, 이시백의 종이, 허물 전 박씨의 천, 허물 뒤 박씨의 등불, 솔이의 가리키기를 확인할 수 있다.

삽화는 1600×900px 가로 16:9 WebP다. 인물은 투명 800×1200px WebP, 발 기준선 y=1152px, 최소 투명 여백 8px다. 허물 전·후 얼굴형과 비녀, 갓 아래 이시백의 얼굴 폭, 솔이의 키와 팔 길이를 각 기준 그림과 대조했다. 그림별 참조와 원본·재생본 해시는 [생성 기록](../../../assets/source/bakssi/generation.json)에 있다.
