## Product direction

KnolStory is a Web-based educational story creation service.
`StoryDocument` remains the canonical source of truth.
The Web app owns service and authoring UX, the Runtime Core interprets story semantics, and Ren'Py Web is the official embedded Story Runtime.

See `AGENTS.md`, `DESIGN.md`, and `docs/architecture/knolstory-final-architecture.md` before implementation.
