# 로딩 캐릭터

## 현재 반복 규칙

최신 사용자 결정은 총4프레임의 **1→2→3→4→1**이다. 1번은 페이지를 넘기기 전의 펼친 책이자, 한 장을 완전히 넘긴 후의 펼친 책이다. 2·3·4는 같은 방향으로 페이지를 들어 책등을 지나 반대쪽에 내리는 중간 동작이다. 별도의 끝 프레임이나 되돌리는 동작을 넣지 않는다. 모든 프레임240ms, 전체960ms로 긴 정지 없이 반복한다.

현재 파일은 토끼전 `story-reading-v4.webp`, 흥부전 `heungbu-reading-v2.webp`, 선녀와 나무꾼 `seonnyeo-reading-v2.webp`, 옹고집전 `onggojib-reading-v2.webp`이다. 기존 첫 세 프레임은 보존하고 각 작품의4번 자세 하나만 생성해 추가했다. 전부480×440, 투명 알파, 무한 반복이다. 이전 버전은 당시 후보로 보존한다.

동작 줄이기는 기존 각 작품의 `*-reading-still-v1.webp` 또는 토끼전 `story-reading-still-v1.webp`의 정지1번을 실제로 선택한다. Web과 native는 `../../loading-stories.json`의 같은 URL을 사용하며 한 로딩에서 고른 작품을 유지한다. 문구는 하나씩4초마다 같은 작품의 다른 항목을 무작위로 골라 교체하고 연속 중복은 피한다. 네 작품을 네 항목씩 배정해 같은 확률로 고르며 문학 안내는 해당 작품과 일치한다. 선택된 애니메이션 하나만 불러오고 반복별 재다운로드는 하지 않는다. Web부트용 자산으로 게임zip에는 넣지 않는다.

원본 캐릭터·원고·Asset ID는 변경하지 않는다.4번은 기존3번을 imagegen 참조로 사용해 페이지/손만 다음 자세로 만들고 기존3번 외곽 크기·위치에 맞춰 정렬했다. 현재4프레임의 원본/정렬 프레임·크기/hash·검증은 `docs/architecture/evidence/story-loading-four-frame-2026-10-20/`에 둔다. 애니메이션의 캔버스 배경도 알파0이다.

## 이전 후보 기록

이전3프레임 후보는 `story-reading-v3.webp`의 세 프레임을 반복한다. 같은 토끼·자라가 책을 함께 읽고 페이지를 들고 넘긴 뒤 다시 읽는다. 480×440, 투명 알파, 무한 반복, 프레임 시간240/240/240ms(총720ms), 약137KiB다. 한 URL을 재사용하며 영상·원격 생성 요청·반복별 이미지 다운로드는 없다.

동작 줄이기는 `<picture>`의 media source로 `story-reading-still-v1.webp`(같은 크기의 첫 프레임, 약45KiB)를 선택한다. CSS만 멈춰서는 animated WebP가 정지하지 않으므로 실제 정지 파일을 사용한다. Web/native는 `../../loading-stories.json`에서 애니메이션과 정지 경로를 공유한다. Web 부트용이므로 Ren’Py 게임 자산 묶음에 포함하지 않는다.

기존 캐릭터를 참고한 imagegen 2×2 프레임 시트에서 각 장면을 추출했다. 인물 외곽 위치로 크기·앉은 높이를 맞추고 투명480×440캔버스에 배치한 뒤 libwebp `img2webp`로 묶었다. ANIM 배경도 명시적으로 알파0이며 각 프레임의 바깥 모서리는 투명하다. 원본 시트와 추출 프레임은 현재 검증 폴더에 보존한다. 압축된 최종 애니메이션 자체에도 모든 프레임이 들어 있다.

앞선 `story-friends.webp`는 이전 정적 로딩 일러스트로 보존한다. 토끼전의 기존 캐릭터 Asset IDs `rabbit-turtle.character.rabbit-white-unified-720x900`, `rabbit-turtle.character.turtle-unified-720x900`를 참고해 사용자 요청으로 생성했다. 기존 원본 캐릭터·원고·Asset ID는 교체하지 않는다.

`story-reading-v1.webp`는 이전 템포의 후보로 보존한다. 현재 v2는 읽기 구간을 길게, 페이지를 넘기는 두 중간 구간은 합계400ms로 맞췄다.

당시 사용자 결정은1→2→3만 같은 속도로 반복하며 읽기 자세의 긴 정지와4번 프레임을 제외한다. v1/v2는 당시 후보로 보존한다.


흥부전·선녀와 나무꾼·옹고집전의3프레임 v1과 그 증거는 `docs/architecture/evidence/story-loading-variants-2026-10-20/`에 보존한다.
