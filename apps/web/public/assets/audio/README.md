# Built-in audio

These four original synthesized WAV assets were created for KnolStory Next. They contain no sampled recordings or third-party media.

- `forest.wav`: 8-second gentle major arpeggio/chord background loop.
- `night.wav`: 8-second quiet minor arpeggio/chord background loop.
- `chime.wav`: 1.2-second decaying bell cue.
- `step.wav`: 0.5-second pair of short noise-envelope footsteps.

Format: mono, 16-bit PCM, 22,050 Hz. Stable IDs and runtime paths live in `packages/asset-registry/src/audio.ts`.

The original project-authored waveforms are dedicated under CC0-1.0 for reuse and redistribution, including commercial use. No attribution is required. This dedication covers these four synthesized audio files, not any legacy images or third-party resources.
