# Pixabay 장면용 자료

14개는 Pixabay Content License 아래 장면 결합 사용 범위로 등록한 조건부 자료다. 원음의 일반 재배포 허가로 바꾸지 않는다. 제목/제공자/원명/라이선스와 검토 hash는 `packages/asset-registry/src/pixabay-audio.json`, 내부 권리 범위는 `audio-service-approvals.json`, 현재 서비스 경계는 `docs/architecture/audio-service-rights.md`가 소유한다. UI에서 원음 다운로드 기능을 제공하지 않으며, 작품 파일에는 기본 자료의 장면 ID만 남긴다. 웹 재생을 위한 데이터 전달은 DRM이 아니고 실제 서비스 범위의 추가 확인이 필요하다. 원본 hash와 개별 페이지 검사는 `docs/architecture/evidence/pixabay-scene-use/individual-review.json`. 공식 약관: https://pixabay.com/service/terms/ .
