# 놀스토리 실행 프로그램과 자료의 고지

놀스토리는 Ren’Py 8.5.3 Web을 사용합니다. Ren’Py와 포함된 자유 소프트웨어의 라이선스 사본은 [RenPy-8.5.3-LICENSE.txt](RenPy-8.5.3-LICENSE.txt)에 보존합니다. 같은 고지는 실행 패키지의 `renpy/LICENSE.txt`에도 있습니다.

- 공식 라이선스 안내: https://www.renpy.org/doc/html/license.html
- Ren’Py 소스: https://github.com/renpy/renpy
- 포함 라이브러리 빌드·소스: https://github.com/renpy/renpy-build
- Web 지원 소스: https://github.com/renpy/renpyweb
- 한국어 무대 글꼴 고지: [NotoSansKR OFL](../assets/licenses/NotoSansKR-OFL.txt)

프로젝트가 소유한 그림의 서비스 사용 허가, CC0 음원, Pixabay의 조건부 장면 사용은 각각 별도 범위를 따릅니다. 이 고지가 프로젝트의 모든 자료를 CC0로 배포한다는 뜻은 아닙니다. 기본 음원은 작품 파일에 원음 대신 자산 ID로 참조하며, 별도의 원음 다운로드 기능을 제공하지 않습니다.
